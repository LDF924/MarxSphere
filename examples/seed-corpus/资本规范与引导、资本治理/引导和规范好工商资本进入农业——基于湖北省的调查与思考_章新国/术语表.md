# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **工商资本** (Industrial and Commercial Capital) | Industrial and Commercial Capital | 指来源于工商业领域的非农资本，包括本地及外地企业、个体工商户、返乡创业者等投入农业领域的资金与资源，在本文中特指以盈利为目的、具备企业化运营能力并参与农业规模经营的资本主体。 |
| **资本下乡** (Capital Going to the Countryside) | Capital Going to the Countryside | 指城市工商业资本向农村地区流动并投资农业及相关产业的过程，是城乡要素再配置的重要表现，本文强调其双重性——既带来现代化动能，也潜藏‘非农化’‘非粮化’等治理风险。 |
| **土地流转** (Rural Land Transfer) | Rural Land Transfer | 指农户将其承包经营权在不改变集体所有制性质和农业用途前提下，依法自愿有偿交由其他主体（如工商企业、合作社）经营的行为，是工商资本进入农业的基础制度安排。 |
| **适度规模经营** (Appropriate Scale Operation) | Appropriate Scale Operation | 指依据区域资源禀赋、劳动力转移程度与农业自然规律，确定的兼顾效率与公平的土地经营规模阈值，本文反对盲目扩大，强调与国情省情和农业生产周期相适应。 |
| **非粮化** (Non-Grain Orientation) | Non-Grain Orientation | 指工商资本主导的农业经营中，大量耕地由粮食作物转向蔬菜、花卉苗木、林果等经济作物的现象，虽提升短期收益，但威胁国家粮食安全战略底线。 |
| **非农化** (Non-Agricultural Use) | Non-Agricultural Use | 指违反土地管理法规，将农用地擅自用于房地产开发、休闲度假村、会所建设等非农业用途，造成耕地永久性损毁，属严重违法违规行为。 |
| **四荒地** (Wasteland, Barren Hills, Sandy Land and Marshland (‘Sihuang’ Lands)) | Wasteland, Barren Hills, Sandy Land and Marshland (‘Sihuang’ Lands) | 指农村集体所有的荒山、荒沟、荒丘、荒滩等未利用或低效利用土地，本文主张优先引导工商资本开发‘四荒地’以规避耕地占用风险。 |
| **利益联结机制** (Interest Linkage Mechanism) | Interest Linkage Mechanism | 指工商资本与农民之间通过土地入股、保底分红、务工就业、订单收购等方式建立的稳定收益共享与风险共担关系，是保障农民权益的核心制度设计。 |
| **风险保障金制度** (Land Transfer Risk Guarantee Fund System) | Land Transfer Risk Guarantee Fund System | 为防范工商企业违约拖欠租金、弃耕抛荒或破坏耕地而设立的专项保证金制度，由地方政府或第三方平台监管，用于补偿农民损失并约束资本行为。 |
| **嵌入性治理** (Embedded Governance) | Embedded Governance | 本文隐含的治理逻辑，指工商资本必须嵌入乡村社会结构与制度环境之中，其经营活动需服从基层治理体系、尊重农民主体地位与村庄公共理性，而非简单套用工业逻辑。 |
| **农业公共性** (Public Nature of Agriculture) | Public Nature of Agriculture | 指农业不仅具有经济功能，更承载粮食安全、生态屏障、文化传承与社会稳定等多重公共价值，构成对工商资本逐利性的根本约束条件。 |
| **种养产业趋同** (Homogenization of Specialty Farming and Breeding Industries) | Homogenization of Specialty Farming and Breeding Industries | 指工商资本盲目跟风投资高收益特色种养业（如蔬菜、苗木），导致区域产业结构雷同、产能过剩与市场恶性竞争，削弱比较优势与抗风险能力。 |
| **村集体代签合同** (Village Collective Signing Contracts on Behalf of Farmers) | Village Collective Signing Contracts on Behalf of Farmers | 指村委会未经农户书面授权即统一签订土地流转协议的行为，虽提高流转效率，但违背《农村土地承包法》关于农户作为流转主体的法定地位，易引发权属纠纷与信任危机。 |
| **农业社会化服务** (Agricultural Socialized Services) | Agricultural Socialized Services | 指面向小农户和新型经营主体提供的专业化、市场化服务，包括农资供应、农机作业、技术推广、仓储物流、品牌营销等，本文视其为工商资本‘补位而不越位’的理想介入领域。 |
| **设施农业** (Protected Agriculture / Facility-Based Agriculture) | Protected Agriculture / Facility-Based Agriculture | 指依托温室大棚、智能灌溉、无土栽培等现代工程技术开展的集约化、工厂化农业生产形态，具有高投入、高技术门槛特征，适合工商资本发挥组织与资本优势。 |
| **三产融合** (Integration of Primary, Secondary and Tertiary Industries) | Integration of Primary, Secondary and Tertiary Industries | 指以农业为基础，延伸产业链至农产品加工（二产）与休闲观光、电商销售、研学体验（三产）的融合发展模式，本文肯定其增值效应，但强调须坚守农业本体与耕地保护红线。 |
| **土地股份合作社** (Land Shareholding Cooperative) | Land Shareholding Cooperative | 农民以承包地经营权作价入股组建的合作组织形式，兼具土地规模化与农民主体性双重特征，是湖北工商资本参与农业的主要组织载体之一。 |
| **公司+合作社** (Company + Cooperative Model) | Company + Cooperative Model | 一种工商资本与农民合作的混合治理结构，企业负责市场对接与资本投入，合作社组织农民生产并参与分配，旨在平衡效率与公平。 |
| **中坚农民** (Core Rural Producers) | Core Rural Producers | 虽未在文中直接命名，但文中多次提及的‘留地种口粮蔬菜的老年农民’‘不愿全流转的理性农户’等群体，体现其作为维系村庄生产生活秩序、抵制资本过度侵蚀的关键中间力量。 |
| **田野调查** (Field Investigation) | Field Investigation | 本文研究方法基础，指研究者深入湖北武汉、荆门、鄂州等地农村一线，通过实地走访、农户访谈、企业座谈与档案查阅等方式获取一手资料，支撑政策判断与问题诊断。 |
| **乡村振兴战略** (Rural Revitalization Strategy) | Rural Revitalization Strategy | 新时代‘三农’工作总抓手，本文将工商资本规范引导置于该国家战略框架下，强调其服务于产业兴旺、生态宜居、生活富裕等核心目标，而非单纯资本扩张。 |
| **中央一号文件** (Central Document No.1) | Central Document No.1 | 中共中央每年发布的第一份文件，聚焦‘三农’工作，本文援引2014年一号文件关于‘新型农业经营主体配套辅助设施用地单列指标’的政策要求，体现政策溯源与执行衔接。 |
| **粮食生产功能区** (Grain Production Functional Zones) | Grain Production Functional Zones | 国家划定的承担主要粮食增产任务的重点区域，本文主张强化对其耕地用途管制，确保工商资本流转土地优先纳入功能区建设体系。 |
| **农业现代化** (Agricultural Modernization) | Agricultural Modernization | 以科技创新、要素集聚、产业融合与治理优化为特征的农业转型升级过程，本文视工商资本为重要推力，但强调必须服从农业现代化的本土性、包容性与可持续性逻辑。 |
| **共同富裕** (Common Prosperity) | Common Prosperity | 中国式现代化的本质要求，本文贯穿此价值导向，指出工商资本发展必须以促进农民增收、防止‘与民争利’、缩小城乡差距为根本尺度，而非仅追求资本回报率。 |

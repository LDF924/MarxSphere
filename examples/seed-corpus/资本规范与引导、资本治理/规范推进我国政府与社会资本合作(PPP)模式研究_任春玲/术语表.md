# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **政府与社会资本合作（PPP）模式** (Public-Private Partnership (PPP) Model) | Public-Private Partnership (PPP) Model | 指政府为提供公共产品或服务，通过特许经营、购买服务、股权合作等方式，与社会资本建立长期合作关系的制度安排；其本质是风险共担、利益共享、权责对等的契约型伙伴关系，而非单纯融资工具。 |
| **项目资本金** (Project Capital Equity) | Project Capital Equity | 指在PPP项目总投资中由投资者以自有资金认缴的、非债务性权益性出资，须真实投入且不得以明股实债、小股大债等形式规避，是衡量项目财务可持续性与风险承担能力的核心指标。 |
| **明股实债** (Equity-in-Form-Debt-in-Substance) | Equity-in-Form-Debt-in-Substance | 指名义上为股权投资（如设立SPV、认购股权），但通过回购承诺、固定收益条款、差额补足等安排实质构成债权投资的行为，违反《国务院关于固定资产投资项目试行资本金制度的通知》（国发〔1996〕35号）关于资本金必须为权益性资金的规定。 |
| **小股大债** (Minority-Equity-Majority-Debt Financing) | Minority-Equity-Majority-Debt Financing | PPP实践中社会资本以少量真股权+大额股东借款方式注资，导致项目公司资本结构虚高、风险错配，实质削弱资本金的风险缓冲功能，被财办金〔2017〕92号文明确禁止。 |
| **绩效考核** (Performance-Based Payment Mechanism) | Performance-Based Payment Mechanism | PPP项目中将政府付费或可行性缺口补助与项目产出质量、运营效率等可量化指标挂钩的动态支付机制，要求建设成本参与绩效考核比例不低于30%，旨在防止‘重建设、轻运营’和固化政府支出责任。 |
| **可行性缺口补助** (Viability Gap Funding (VGF)) | Viability Gap Funding (VGF) | 当使用者付费不足以覆盖PPP项目全生命周期成本与合理回报时，由政府提供的差额补贴，其支付须严格绑定绩效考核结果，是当前我国PPP项目占比最高（59.3%）、财政压力最显著的付费机制类型。 |
| **物有所值评价（VfM）** (Value for Money Assessment) | Value for Money Assessment | PPP项目前期核心论证环节之一，通过定性与定量分析比较PPP模式与传统政府采购模式在全生命周期成本、风险分配、效率提升等方面的综合效益，是项目入库前置条件。 |
| **财政承受能力论证** (Fiscal Affordability Assessment) | Fiscal Affordability Assessment | 评估地方政府在项目合作期内各年度财政支出责任占一般公共预算支出比例是否超过10%红线的法定程序，系PPP项目财政可持续性的刚性约束机制。 |
| **管理库与储备清单库** (Management Library and Reserve List) | Management Library and Reserve List | 全国PPP综合信息平台实施的分级分类管理制度：储备清单库收纳处于识别阶段的孵化项目；管理库收录完成‘两评’并进入准备、采购、执行或移交阶段的合规项目，是财政支出责任确认的唯一依据。 |
| **财办金〔2017〕92号文** (Circular No. 92 of the Ministry of Finance (2017)) | Circular No. 92 of the Ministry of Finance (2017) | 财政部发布的《关于规范政府和社会资本合作（PPP）综合信息平台项目库管理的通知》，确立PPP项目入库‘负面清单’与‘正向标准’，首次系统界定‘伪PPP’特征，成为规范PPP发展的标志性政策文件。 |
| **国资发财管〔2017〕192号文** (Circular No. 192 of SASAC (2017)) | Circular No. 192 of SASAC (2017) | 国务院国资委发布的《关于加强中央企业PPP业务风险管控有关事项的通知》，聚焦央企参与PPP的合规边界，严禁‘名股实债’、违规担保及表外融资，强化央企作为社会资本方的风险主体责任。 |
| **政府履约保证** (Government Performance Guarantee) | Government Performance Guarantee | PPP合同中政府为降低社会资本风险而作出的承诺性安排，包括最低需求量、费用支付、特许期、价格补偿等，但须符合《预算法》及防范隐性债务要求，不得构成违法违规举债担保。 |
| **弹性特许期** (Flexible Concession Period) | Flexible Concession Period | PPP实践中政府承诺根据项目实际运营绩效动态调整特许经营期限的安排，虽具激励性，但因加剧融资不确定性与监管复杂性，被本文视为不合理保证机制之一。 |
| **伪PPP** (Pseudo-PPP) | Pseudo-PPP | 形式上采用PPP结构但实质违背其风险共担、运营导向、财政可持续等核心原则的项目，典型表现为纯工程导向、无实质运营、政府兜底回报或固化支出责任，属92号文重点清退对象。 |
| **两评** (Two Assessments) | Two Assessments | 指PPP项目立项前必须完成的‘物有所值评价（VfM）’与‘财政承受能力论证’，二者共同构成项目财政合规性与经济合理性的双重门槛，缺一不可。 |
| **可用性服务费** (Availability Payment) | Availability Payment | 政府付费类PPP项目中，基于项目设施建成后达到约定技术标准并持续可用状态而支付的费用，须与运维绩效服务费分离且均需挂钩考核，防止‘竣工即付’异化为BT模式。 |
| **运营虚置** (Operational Tokenism) | Operational Tokenism | PPP项目中社会资本仅承担建设职能而未实质性参与后期运营管理，或运营责任流于形式、缺乏绩效约束，导致公共服务质量无法保障，是PPP泛化异化的典型表现。 |
| **隐性风险** (Latent Risks) | Latent Risks | PPP实践中因制度不健全、契约不完备或执行偏差所积累的未显性化财政与金融风险，如政府过度担保引发的或有负债、明股实债导致的资产负债表外风险等。 |
| **重规模转向重质量** (From Scale-Oriented to Quality-Oriented Development) | From Scale-Oriented to Quality-Oriented Development | 我国PPP发展新阶段的战略转向，强调从追求数量扩张转向强化项目全生命周期合规性、绩效导向性与财政可持续性，体现高质量发展理念在基础设施投融资领域的落地。 |
| **社会资本** (Social Capital) | Social Capital | 依法设立、具备相应投资建设运营能力的境内企业或联合体，作为PPP项目中与政府平等合作的市场主体，须以真金白银投入资本金并承担实质性运营风险，区别于财务投资人或通道方。 |
| **财政支出责任** (Fiscal Expenditure Obligation) | Fiscal Expenditure Obligation | PPP项目合作期内政府依据合同约定需承担的股权投资、运营补贴、配套投入、风险承担、配套付费等各项财政支出义务，须纳入中长期财政规划并接受10%支出上限硬约束。 |
| **合作伙伴关系** (Partnership Relationship) | Partnership Relationship | PPP模式的核心治理逻辑，强调政府与社会资本基于契约精神的平等协商、专业分工与动态协同，超越传统‘甲方—乙方’行政隶属关系，形成以公共服务效能最大化为目标的新型政企关系。 |
| **风险共担** (Risk Sharing) | Risk Sharing | PPP项目中依据‘最有意愿承担或最有能力控制’原则，在政府与社会资本间科学划分政治、法律、市场、建设、运营等各类风险，并通过合同条款予以固化，是PPP可持续运行的制度基石。 |
| **全生命周期管理** (Whole-Life-Cycle Management) | Whole-Life-Cycle Management | PPP项目从识别、准备、采购、执行到移交的五阶段闭环管理体系，要求在各环节嵌入合规审查、绩效监控与动态调整机制，确保项目始终符合公共利益与财政安全目标。 |
| **示范项目** (Demonstration Projects) | Demonstration Projects | 财政部遴选的具有可复制、可推广价值的PPP典型案例，实行更高标准的‘两评’要求与更严绩效监管，截至2018年3月总体落地率达83.5%，发挥引领规范发展的标杆作用。 |

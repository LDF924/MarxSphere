# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **社会资本** (Social Capital) | Social Capital | 本文指嵌入于农民专业合作社运作中的结构性资源，具体表现为信任、规范与网络三重维度的有机统一体；它既包括基于亲缘地缘的‘特殊信任’等非正式内生性资源，也涵盖制度性规范与组织化网络等可被测量、转化和动员的行动性资产，是合作社提供排他性公共物品、实现金融—风险—信息—政策资本转化的核心基础。 |
| **熟人信任** (Guānxi-based Trust) | Guānxi-based Trust | 中国乡土社会中以亲缘、地缘和长期互动为基础形成的‘特殊信任’，具有高度情境依赖性与关系嵌入性；在隆信合作社中表现为社员对理事长闻辉及其家族网络的高度信赖，构成合作发起与初始动员的关键行动逻辑，但亦制约组织向契约化、跨区域‘普遍信任’转型。 |
| **特殊信任** (Particularized Trust) | Particularized Trust | 区别于基于规则与制度的‘普遍信任’，指依托血缘、地缘、声誉及社会相似性（如共同价值观念、风俗习惯）建立的差异化信任关系；本文强调其作为中国农民合作经济组织内生性启动机制的功能，同时指出其在规模化扩张中面临信用审核边界受限的结构性瓶颈。 |
| **制度性规范** (Institutional Norms) | Institutional Norms | 由国家法律（如《农民专业合作社法》）、地方规章（如S县规范化建设标准）及合作社内部章程（如《隆信渔业合作社章程》）共同构成的正式规则体系，核心要求产权明晰、权责明确、财务规范与民主治理，是保障合作社可持续运行和抵御投机行为的刚性约束机制。 |
| **互惠性规范** (Reciprocal Norms) | Reciprocal Norms | 合作社内部自发形成并被成员广泛认同的非正式行为准则，体现为‘贷款三优’（授信优先、放贷优先、利率优惠）、技术共享、信息共用、统一采购与盈余返还等实践安排；其本质是普特南所言‘普遍互惠’，通过重复博弈与声誉机制降低交易成本、强化集体行动能力。 |
| **网络成分** (Network Composition) | Network Composition | 指合作社所嵌入的社会网络中各类行动主体的类型构成，本文实证识别出政府机构（畜牧水产局、农工办）、金融机构（信用联社）、科研单位（江西农大）、市场主体（饲料商、经纪人、捕鱼队）及农户群体等多元异质性节点，构成合作社资源整合与功能拓展的结构性基础。 |
| **网络联结强度** (Network Tie Strength) | Network Tie Strength | 衡量合作社与外部关键主体间关系紧密程度的指标，文中突出表现为与S县信用联社‘战略合作协议’下的高额度授信、贴息贷款及风险共担机制，以及与县公安局经侦大队共建警务室的深度协同，反映强联结对金融可得性与风险控制能力的决定性作用。 |
| **网络集中度** (Network Centrality) | Network Centrality | 指合作社在网络结构中处于枢纽位置的程度，文中体现为理事长闻辉凭借其技术推广站站长身份、家族政商网络（胞弟任央行行长、女婿任县政府办副主任）及行业权威，使各类外部资源（政策、资金、技术）高度汇聚于合作社，形成‘以点带面’的资源吸附效应。 |
| **结构洞** (Structural Hole) | Structural Hole | 指合作社作为连接不同网络子群（如政府—金融—科研—生产者）的关键中介所占据的战略位置；文中显示其有效弥合了行政系统、市场体系与小农个体间的制度缝隙，通过信息桥接与信任传递实现跨域资源整合，但亦隐含对核心人物个人网络的路径依赖风险。 |
| **嵌入性** (Embeddedness) | Embeddedness | 本文援引格兰诺维特理论，强调合作社并非孤立运行的经济组织，而是深度嵌入乡土社会关系网络与正式制度环境之中；其成功依赖于‘信任—规范—网络’三者的协同演化，脱离此嵌入语境的制度移植往往失效。 |
| **俱乐部型组织** (Club-like Organization) | Club-like Organization | 指农民专业合作社兼具排他性与非竞争性的组织属性：仅对社员提供技术培训、信贷支持、品牌营销等专属服务（排他性），而社员共享服务的边际成本趋近于零（非竞争性），该特性使其成为解决农村公共物品供给失灵的重要微观载体。 |
| **社会资本转化** (Social Capital Conversion) | Social Capital Conversion | 本文核心命题，指合作社将无形的社会资本（信任、规范、网络）具象化为可操作的经济资本形态：如信任转化为授信额度（金融资本）、互惠规范转化为联保基金（风险控制资本）、政商网络转化为项目经费与政策倾斜（政策资本）、技术传播网络转化为标准化生产能力（信息资本）。 |
| **社员联保** (Member Joint Liability) | Member Joint Liability | 一种基于熟人社会信用的内生性风险分担机制，由5–7户社员自愿组成联保小组，实行连带责任与民主监督；其有效性高度依赖村庄舆论压力与社会相似性支撑，是正式金融制度与乡土规范嫁接的典型制度创新。 |
| **联保基金** (Joint Liability Fund) | Joint Liability Fund | 合作社社员按贷款额8%缴纳、存入专户的互助性风险准备金，用于代偿违约贷款；该机制将社会资本中的互惠规范制度化，形成‘信用—责任—收益’闭环，实现信贷风险内部化与‘零风险’运营目标。 |
| **三优服务** (Three-Priority Service) | Three-Priority Service | 隆信合作社对社员提供的差异化金融服务承诺，即贷款授信优先、放款流程优先、执行利率优惠，本质是将理事长个人声誉与合作社集体信用资本化，转化为可量化的金融可得性优势，构成吸引农户入社的核心制度吸引力。 |
| **普遍互惠** (Generalized Reciprocity) | Generalized Reciprocity | 普特南定义的高生产性社会资本形式，指成员预期未来能从共同体中获益而自愿让渡当前利益（如承担联保责任、缴纳联保基金）；在隆信合作社中体现为技术共享、信息开放与盈余返还，通过重复博弈与声誉积累抑制机会主义行为。 |
| **声誉机制** (Reputation Mechanism) | Reputation Mechanism | 祖克尔提出的信任生成路径之一，指个体或组织因过往履约记录（如闻辉38年养殖经历、合作社连续三年零不良贷款）积累的可信度，成为外部主体（信用联社、惠州市农业局）进行合作决策的核心依据，构成社会资本可测量、可传递的关键中介变量。 |
| **社会相似性** (Social Similarity) | Social Similarity | 祖克尔界定的信任基础维度，指社员间在地域来源（95%来自S县）、职业背景（养鱼户）、价值观念（重信守诺）等方面的同质性程度；高相似性降低认知摩擦与监督成本，是熟人社会中互惠规范得以自发演化的前提条件。 |
| **政策平台** (Policy Platform) | Policy Platform | 合作社依托核心成员政商网络（如理事长女婿任县政府办副主任）构建的非正式政策信息获取与诉求表达渠道，使其能精准对接农业产业化、绿色认证、课题申报等政策红利，体现社会资本在制度环境中‘穿针引线’的能动性功能。 |
| **信用审核边界** (Boundary of Credit Assessment) | Boundary of Credit Assessment | 指合作社规模化扩张过程中遭遇的内生性约束——当社员数量超出理事长个人社会关系网络覆盖范围时，基于熟人信任的信用甄别机制失效，倒逼组织转向契约化、数字化风控体系，揭示‘特殊信任’向‘普遍信任’转型的现实紧迫性。 |
| **五化** (Five Modernizations) | Five Modernizations | 隆信合作社自我标定的规范化发展目标，即产权明晰化、管理民主化、财务规范化、服务优质化、经营效益化，是制度性规范在操作层面的具体展开，体现合作社在保持乡土适应性的同时追求现代治理能力的双重面向。 |
| **地名商标** (Geographical Indication Trademark) | Geographical Indication Trademark | 合作社以‘S鳙’注册的区域公共品牌，既是质量信誉的符号化载体，也是整合分散农户、对接高端市场的制度工具；其成功依赖地方政府背书、央视传播与合作社集体行动能力，彰显社会资本向品牌资本转化的完整链条。 |
| **嵌入式治理** (Embedded Governance) | Embedded Governance | 指合作社治理结构既非纯粹科层制亦非完全自治，而是将正式制度（章程、财务制度）嵌入非正式秩序（村庄舆论、人情网络）之中，如通过联保小组长包片制实现基层监督，体现中国乡村合作组织‘制度理性’与‘关系理性’的辩证统一。 |
| **风险防火墙** (Risk Firewall) | Risk Firewall | 合作社与信用联社共建的双重风险防控体系：前端以社员联保实现道德约束与责任共担，后端以联保基金提供财务兜底；二者均以社会资本（信任、互惠、网络）为底层支撑，构成金融资本下乡的安全阀机制。 |
| **借来的信任** (Borrowed Trust) | Borrowed Trust | 维莱斯·伊本内兹提出的核心概念，指在缺乏直接了解的情境下，行动者A因信任中介B，而间接信任C（如信用社因信任闻辉而放贷给社员）；本文将其操作化为合作社信用传导机制，凸显网络在信任扩散与信用增级中的结构性作用。 |

# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **社会主义市场经济体制** (Socialist Market Economy System) | Socialist Market Economy System | 中国共产党领导下的、以公有制为主体多种所有制经济共同发展、市场在资源配置中起决定性作用和更好发挥政府作用相结合的基本经济制度安排，是资本得以存在并被规范引导的根本制度载体。 |
| **资本的双重功能** (Dual Function of Capital) | Dual Function of Capital | 指社会主义市场经济条件下资本兼具‘竞争变强’（激活生产力、优化生产关系、驱动个体发展）与‘扶弱变强’（服务共同富裕、均衡区域发展、践行生态文明）的辩证统一功能，体现社会主义制度对资本逻辑的超越性引导。 |
| **竞争变强功能** (Competitive Strengthening Function) | Competitive Strengthening Function | 资本在社会主义市场经济中通过激发劳动者能力提升、推动生产工具智能化、拓展劳动对象领域等方式，促使社会成员在竞争中实现素质跃升与发展增强的内生性功能。 |
| **扶弱变强功能** (Weakness-to-Strength Transformation Function) | Weakness-to-Strength Transformation Function | 在党的全面领导和社会主义制度约束下，资本被赋予帮扶弱势群体提升能力、支持欠发达地区产业发展、促进基本公共服务均等化的社会责任性功能，是中国特色资本治理的核心标识。 |
| **资本的逐利本性** (Profit-Seeking Nature of Capital) | Profit-Seeking Nature of Capital | 资本内在的价值增殖冲动，表现为对剩余价值的持续追逐，构成其运行的根本动力，亦是需要通过制度约束加以规范以防止无序扩张与社会危害的根源性特征。 |
| **党的领导与资本治理** (Party Leadership in Capital Governance) | Party Leadership in Capital Governance | 指中国共产党作为最高政治领导力量，通过顶层设计、制度建构、组织保障和理论创新，对各类资本的准入、运行、分配与退出全过程实施方向引领与刚性约束的治理机制。 |
| **社会主义基本经济制度** (Socialist Basic Economic System) | Socialist Basic Economic System | 由公有制为主体、多种所有制经济共同发展，按劳分配为主体、多种分配方式并存，社会主义市场经济体制三者构成的有机整体，为资本良性运行提供根本制度支撑和合法性基础。 |
| **共同富裕** (Common Prosperity) | Common Prosperity | 中国特色社会主义的本质要求和中国式现代化的重要特征，强调在高质量发展中逐步缩小城乡、区域和群体间差距，通过初次分配、再分配、第三次分配协调配套实现全体人民共享发展成果。 |
| **三次分配制度** (Three-Tiered Distribution System) | Three-Tiered Distribution System | 以市场机制主导的初次分配、政府调节主导的再分配、社会道德驱动的第三次分配（慈善捐赠、志愿服务等）构成的系统性收入分配格局，是资本履行社会责任、助力共同富裕的关键制度通道。 |
| **资本生态逻辑** (Ecological Logic of Capital) | Ecological Logic of Capital | 指在绿色发展理念指引下，资本从单纯追求经济利润转向兼顾生态环境效益的运行范式，体现‘绿水青山就是金山银山’理念对资本行为的重塑与规训。 |
| **两山论** (Two Mountains Theory) | Two Mountains Theory | 习近平提出的‘绿水青山就是金山银山’科学论断，确立了生态环境资源的资本化属性与可持续开发原则，构成社会主义市场经济中资本承担生态文明建设责任的理论基石。 |
| **新发展理念** (New Development Philosophy) | New Development Philosophy | 创新、协调、绿色、开放、共享五大理念构成新时代资本运行的方向标，系统规定资本在科技投入、区域平衡、生态保护、对外开放与成果共享等维度的行为边界与价值导向。 |
| **资本无序扩张** (Disorderly Expansion of Capital) | Disorderly Expansion of Capital | 指资本脱离实体经济、规避监管、形成垄断、操纵市场、侵蚀意识形态或破坏生态等违背社会主义发展方向的异化行为，是资本治理的重点防范对象。 |
| **高水平社会主义市场经济体制** (High-Level Socialist Market Economy System) | High-Level Socialist Market Economy System | 以有效市场与有为政府更好结合为特征，具备法治化、国际化、便利化营商环境，能充分激发各类资本活力并实现其与国家战略深度耦合的现代经济体制。 |
| **资本治理** (Capital Governance) | Capital Governance | 在党的领导下，依托社会主义基本经济制度和国家治理体系，对各类资本的生成、配置、运行、收益与风险实施全过程、全链条、协同化规范引导的制度实践与理论体系。 |

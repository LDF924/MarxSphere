# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **政府和社会资本合作（PPP）** (Public-Private Partnership (PPP)) | Public-Private Partnership (PPP) | 指政府与社会资本基于合同关系，在公共服务和基础设施领域开展的长期合作模式，强调风险共担、收益共享、全生命周期管理，是我国推进国家治理现代化和财政可持续的重要制度安排。 |
| **绿色发展** (Green Development) | Green Development | 以节约资源、保护环境、低碳循环为基本路径，实现经济社会发展与生态环境保护协同共进的发展范式，是生态文明建设的核心实践导向。 |
| **生态文明** (Ecological Civilization) | Ecological Civilization | 中国特色社会主义文明形态之一，强调人与自然和谐共生，以制度保障、价值引领和系统治理推动生态优先、绿色发展。 |
| **污染防治和绿色低碳PPP项目** (PPP Projects for Pollution Prevention and Green-Low-Carbon Development) | PPP Projects for Pollution Prevention and Green-Low-Carbon Development | 聚焦水环境治理、污水垃圾处理、林业碳汇、新能源基建等领域的PPP项目，具有显著正外部性、长周期性和财政支出刚性特征，是PPP支持生态文明建设的主战场。 |
| **三重转变** (Triple Transformation) | Triple Transformation | 指PPP模式推动的政府角色从供给者向监督者/合作者转变、社会资本从观望者向建设者/运营者转变、公共服务供给质量从单一低效向市场化高质量转变的系统性变革。 |
| **两手合力** (Dual-Hand Coordination) | Dual-Hand Coordination | 指政府‘有形之手’与市场‘无形之手’协同发力，通过政策引导、财政撬动与机制创新共同驱动PPP项目服务国家战略的治理逻辑。 |
| **按效付费** (Payment by Results) | Payment by Results | PPP绩效管理的核心机制，依据项目产出质量、服务效果和公众满意度等可量化指标进行财政支付，强化激励约束与责任闭环。 |
| **财政承受能力论证** (Fiscal Affordability Assessment) | Fiscal Affordability Assessment | PPP项目入库前的法定程序，测算项目全生命周期财政支出责任占一般公共预算支出比例，严守10%红线，防范隐性债务风险。 |
| **真股权融资** (Genuine Equity Financing) | Genuine Equity Financing | 社会资本以自有资金真实出资、同股同权、不附加兜底承诺或明股实债条款的资本金筹集方式，是规范PPP资本结构、防范金融风险的关键要求。 |
| **生态环境导向的开发模式（EOD）** (Ecology-Oriented Development (EOD)) | Ecology-Oriented Development (EOD) | 以生态治理为基础、关联产业开发为反哺的融合开发模式，通过‘肥瘦搭配’实现环境效益与经济效益统筹平衡，是破解PPP项目造血功能不足的重要创新路径。 |
| **PPP+REITs** (PPP-Linked Real Estate Investment Trusts) | PPP-Linked Real Estate Investment Trusts | 以PPP项目收益权或项目公司股权为底层资产发行的基础设施公募REITs，旨在盘活存量资产、拓宽退出渠道、提升社会资本参与积极性。 |
| **PPP+ABS** (PPP-Linked Asset-Backed Securities) | PPP-Linked Asset-Backed Securities | 以PPP项目未来现金流（如使用者付费、政府补贴）为支撑发行的资产证券化产品，可优化融资结构、匹配资金期限、降低综合融资成本。 |
| **绿有所值** (Green Value for Money (GVfM)) | Green Value for Money (GVfM) | 在传统‘物有所值’（VfM）评价基础上，新增生态环境效益量化评估维度，构建兼顾经济效率与生态正外部性的PPP项目可行性论证新标准。 |
| **ESG治理理念** (Environmental, Social and Governance (ESG) Principles) | Environmental, Social and Governance (ESG) Principles | 将环境绩效、社会责任与公司治理纳入PPP项目全生命周期管理体系，推动项目设计、建设、运营各环节落实减污降碳、社区参与和透明问责要求。 |
| **乡村振兴PPP项目** (PPP Projects for Rural Revitalization) | PPP Projects for Rural Revitalization | 聚焦脱贫地区环保短板补缺、农村人居环境整治、生态产业化等领域的PPP实践，体现‘绿水青山就是金山银山’在基层落地的制度载体。 |
| **长江经济带PPP项目** (PPP Projects in the Yangtze River Economic Belt) | PPP Projects in the Yangtze River Economic Belt | 服务于流域协同治理与绿色转型的跨区域PPP集群，强调上下游生态补偿、跨省联防联控和一体化基础设施布局。 |
| **分行业绩效指标体系** (Sector-Specific Performance Indicator System) | Sector-Specific Performance Indicator System | 针对污水处理、垃圾焚烧、生态修复等细分领域制定的标准化、可比性、可验证的PPP项目绩效考核指标集合，支撑‘按效付费’精准落地。 |
| **隐性债务** (Hidden Local Government Debt) | Hidden Local Government Debt | 地方政府通过PPP、政府购买服务等名义违规举债形成的、未纳入预算管理的债务，其识别与防控是PPP规范发展的核心财政纪律。 |
| **社会资本方专业性优势** (Professional Advantages of Private Partners) | Professional Advantages of Private Partners | 指社会资本在技术研发、运营管理、成本控制和商业模式创新等方面的能力禀赋，是PPP提升公共服务供给质量与效率的核心动能。 |
| **使用者付费** (User Charges) | User Charges | PPP项目中由终端用户直接支付服务费用的机制，体现‘污染者付费’原则和市场化定价逻辑，是增强项目可持续性的关键财务基础。 |
| **全生命周期绩效管理** (Whole-Life-Cycle Performance Management) | Whole-Life-Cycle Performance Management | 覆盖PPP项目识别、准备、采购、建设、运营至移交各阶段的动态化、标准化、信息化绩效监控与评价体系，确保公共价值持续实现。 |
| **生态产品价值实现** (Realization of Ecological Product Value) | Realization of Ecological Product Value | 通过市场化交易、生态补偿、绿色金融等机制，将森林、湿地、清洁空气等生态产品的使用价值转化为可计量、可交易、可分配的经济价值的过程。 |
| **绿色金融支持项目储备库** (Green Finance Supported Project Reserve List) | Green Finance Supported Project Reserve List | 由生态环境部、财政部等部门联合建立的优质绿色项目名录，为银行信贷、绿色债券、政策性基金提供精准对接通道，强化PPP项目的绿色融资赋能。 |
| **社会资本参与率** (Private Sector Participation Rate) | Private Sector Participation Rate | PPP项目中由民营企业作为主要社会资本方签约的数量占比，是衡量市场公平准入程度和民间投资活力的核心监测指标。 |
| **阳光运行** (Transparent Operation) | Transparent Operation | 依托全国PPP综合信息平台实现项目全要素、全流程、全主体信息公开，接受社会监督，是防范权力寻租、保障公共利益的根本制度保障。 |

# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **信息资本** (Information Capital) | Information Capital | 本文中指农户所拥有的、可转化为绿色生产决策优势的综合性信息资源禀赋，由硬信息资本（如电视、互联网、政府宣传渠道等有形信息基础设施）与软信息资本（包括信息获取能力、信息质量感知、信息效果感知及多源信息渠道整合能力）共同构成，具有生产要素属性和资本增殖潜力，是影响农户技术采纳行为的关键前置变量。 |
| **无公害农药施用意愿与行为的悖离** (Discrepancy between Willingness and Behavior in Pollution-Free Pesticide Adoption) | Discrepancy between Willingness and Behavior in Pollution-Free Pesticide Adoption | 特指农户在主观上明确表达愿意施用无公害农药（意愿存在），但在实际农业生产中并未采取相应施用行为（行为缺失）的认知—行动断裂状态，是本文核心因变量，反映绿色技术推广中的‘知行鸿沟’，区别于‘无意愿无行为’或‘有行为无意愿’两类情形。 |
| **技术感知易用性** (Perceived Ease of Use (PEOU)) | Perceived Ease of Use (PEOU) | 基于技术接受模型（TAM）的核心构念，在本文语境中专指农户对无公害农药施用技术在操作难度、学习成本、适配现有农事流程等方面的主观判断，是连接信息资本输入与实际行为输出的关键认知中介机制。 |
| **社会规范** (Social Norms) | Social Norms | 植根于中国农村‘熟人社会’结构的非正式制度约束，表现为同村农户间关于施药方式的共识性期待、舆论评价与从众压力，本文将其操作化为农户对‘周边多数人是否认可/采用无公害农药’的感知强度，并作为调节信息资本效力的关键情境变量。 |
| **大农业观** (Holistic Agricultural Perspective) | Holistic Agricultural Perspective | 本文理论背景中提出的国家战略导向性概念，强调农业不仅是种植业，而是涵盖产前、产中、产后全链条，融合生态、经济、社会多重目标的系统性产业观，为绿色施药等技术推广提供宏观价值锚点与政策合法性基础。 |
| **SOR理论模型** (Stimulus-Organism-Response Model) | Stimulus-Organism-Response Model | 本文构建分析框架的理论基石，将‘信息资本’视为外部刺激（S），‘技术感知易用性’作为内在认知有机体（O），‘无公害农药施用行为’界定为最终响应（R），用以解析农户绿色技术采纳中意愿—行为转化的黑箱机制。 |
| **信息获取能力** (Information Acquisition Capacity) | Information Acquisition Capacity | 信息资本的软要素维度之一，指农户主动识别、筛选、理解并内化农业技术信息的能力，操作化为受教育程度、村干部身份及亲属政治网络等结构性指标，体现个体信息处理的能动性。 |
| **信息获取渠道** (Information Channels) | Information Channels | 信息资本的结构性维度，指农户实际利用的信息来源多样性与频次，包括人际传播（亲友）、大众媒介（电视/网络）、市场反馈（农资店）及行政渠道（政府宣讲），其数量与使用频率共同表征信息接入广度。 |
| **信息获取质量** (Information Quality Perception) | Information Quality Perception | 农户对不同渠道所获农业技术信息的准确性、时效性、实用性与可信度的主观评价，是信息资本有效性的重要前提，直接影响技术认知建构与风险判断。 |
| **信息效果感知** (Perceived Information Effectiveness) | Perceived Information Effectiveness | 农户对自身所掌握政策与技术信息在指导生产实践、规避风险、提升收益等方面实际效用的评估，通过其对环境治理、绿色发展等政策的了解程度量测，反映信息内化后的工具理性认知。 |
| **绿色施药** (Green Pest Control) | Green Pest Control | 本文核心政策实践概念，特指以无公害农药替代高毒高残留化学农药的精准化、减量化施用行为，是农业面源污染防控与农产品质量安全保障的技术载体，体现‘化肥农药减量增效’国家政策的具体落地形态。 |
| **农户行为** (Farmer Behavior) | Farmer Behavior | 本文聚焦的微观主体实践，专指小农户在家庭经营单元内对无公害农药的实际采购、储存、配比与田间施用等可观察、可验证的操作性行动，区别于态度、意愿等心理变量。 |
| **田野调查** (Field Survey) | Field Survey | 本文实证研究的方法论基础，指研究团队于2023年在甘肃五市七县开展的结构化入户访谈，覆盖650户有效样本，通过问卷设计、培训访员、多轮质控等程序确保数据生态真实性与区域代表性。 |
| **中介效应** (Mediating Effect) | Mediating Effect | 本文验证的技术感知易用性在信息资本影响行为悖离过程中的传导机制：信息资本并非直接改变行为，而是首先提升农户对技术易用性的主观判断，进而降低采纳门槛，最终减少意愿—行为偏差。 |
| **调节效应** (Moderating Effect) | Moderating Effect | 本文揭示的社会规范对信息资本效力的边界条件作用：当社区社会规范强度较高时，信息资本对行为转化的促进作用被强化；反之，在低规范环境中，即使信息资本充裕，其正向效应亦显著衰减。 |
| **信息不对称** (Information Asymmetry) | Information Asymmetry | 本文理论溯源的关键前提，指农户与技术供给方（政府、企业、专家）之间在无公害农药功效、使用方法、市场回报等关键信息上的分布不均，构成绿色技术推广的主要障碍，而信息资本正是缓解该问题的核心能力。 |
| **有限理性** (Bounded Rationality) | Bounded Rationality | 行为经济学理论支撑，解释为何农户即便拥有信息也不必然采纳绿色技术——受限于认知能力、时间精力与环境复杂性，其决策追求‘满意解’而非最优解，故需通过提升信息资本降低决策不确定性。 |
| **熟人社会** (Acquaintance Society) | Acquaintance Society | 费孝通提出并被本文延伸应用的中国乡村社会学经典概念，指以血缘、地缘为基础的强关系网络，其衍生的社会规范、互惠信任与声誉机制，构成农户绿色生产行为选择的隐性制度环境。 |
| **农业绿色高质量发展** (Green and High-Quality Agricultural Development) | Green and High-Quality Agricultural Development | 本文政策语境下的终极目标，强调在保障粮食安全前提下，通过资源节约、环境友好、优质高效的技术路径实现农业现代化，无公害农药推广是其关键微观抓手。 |
| **化肥农药减量增效** (Reduction and Efficiency Enhancement of Chemical Fertilizers and Pesticides) | Reduction and Efficiency Enhancement of Chemical Fertilizers and Pesticides | 国家‘十四五’规划明确部署的核心政策任务，要求在控制投入总量的同时提升利用效率，本文将无公害农药施用视为落实该政策的技术接口与农户响应载体。 |

# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **民间资本管理公司** (Private Capital Management Company) | Private Capital Management Company | 指由符合条件的自然人、企业法人和其他经济组织发起，经地方政府批准设立，在特定区域内开展股权投资、债权投资、短期财务性投资及受托资产管理等业务的非银行类地方金融组织，是山东省推动民间融资阳光化、规范化的重要制度载体。 |
| **民间融资阳光化** (Sunlighting of Informal Financing) | Sunlighting of Informal Financing | 指通过制度设计与监管引导，将游离于正规金融体系之外的民间借贷活动纳入合法、透明、可监测的轨道，实现资金来源可溯、资金用途可控、风险暴露可见的规范化治理目标。 |
| **地方金融监管体系** (Local Financial Regulatory System) | Local Financial Regulatory System | 指省、市、县三级纵向贯通、权责明晰的金融监管架构，以《山东省地方金融条例》为法律基础，对民间融资机构实施准入管理、分类评级、年审监督和风险处置的全过程监管机制。 |
| **分类评级** (Classification and Rating) | Classification and Rating | 山东省地方金融监管部门依据资本实力、资产质量、合规水平、风控能力等维度对民间资本管理公司进行动态等级评定（如A—E级），评级结果直接影响其业务范围拓展、创新试点资格及区域经营权限。 |
| **业务许可制** (Business License System) | Business License System | 区别于早期的设立审批制，指自2017年《山东省地方金融条例》实施后，民间资本管理公司须通过持续符合监管指标要求方可获得并维持业务许可证，强调事中事后监管与实质合规。 |
| **债权投资** (Credit Investment) | Credit Investment | 民间资本管理公司以自有或定向募集资金向实体经济主体提供有明确期限、利率及担保安排的贷款类投资，是聊城市该类机构占比近半（46.06%）的核心业务形态。 |
| **短期财务性投资** (Short-term Financial Investment) | Short-term Financial Investment | 指以获取利息、价差或流动性收益为目的，期限通常在一年以内、不谋求控制权或战略协同的标准化金融产品投资，占聊城市民间资本管理公司总投资额的52.99%。 |
| **风险拨备制度** (Risk Provisioning System) | Risk Provisioning System | 要求机构按资产风险分类结果足额计提损失准备金的内控机制，借鉴银行贷款五级分类标准，旨在增强抵御信用风险与流动性风险的财务缓冲能力。 |
| **资产分类制度** (Asset Classification System) | Asset Classification System | 依据投资标的的风险特征、还款保障及逾期状况，将资产划分为正常、关注、次级、可疑、损失五类的内部管理制度，是风险拨备计提与处置决策的基础依据。 |
| **创新业务试点** (Innovative Business Pilot Program) | Innovative Business Pilot Program | 山东省允许资质优良的民间资本管理公司在监管框架下开展债券投资、私募基金管理、不良资产处置、资产证券化等增量业务的试验性政策安排，需满足分类评级、资本充足率等前置条件。 |
| **差异化发展路径** (Differentiated Development Pathway) | Differentiated Development Pathway | 针对聊城市县域经济结构多元、融资需求异质性强的特点，鼓励民间资本管理公司立足本地产业禀赋与客户画像，构建特色化产品体系与风控模型的发展策略。 |
| **非现场监管** (Off-site Supervision) | Off-site Supervision | 监管机构通过定期报送的财务报表、业务台账、风险监测数据等信息，运用数据分析技术对民间资本管理公司合规性与稳健性进行远程评估的常态化监管方式。 |
| **现场监管** (On-site Supervision) | On-site Supervision | 监管人员赴机构实地开展合规检查、账务核查、系统测试及高管约谈等穿透式监管活动，是验证非现场监管结论、识别隐性风险的关键手段。 |
| **受托资产管理** (Entrusted Asset Management) | Entrusted Asset Management | 民间资本管理公司接受委托方（如地方政府平台、村集体、中小微企业）委托，对其特定资产进行专业化运营、保值增值及风险隔离的服务型业务，属监管允许的创新方向之一。 |
| **资本金约束** (Capital Constraint) | Capital Constraint | 指民间资本管理公司业务规模受注册资本金及股东定向借款额度双重限制的监管要求，决定了其风险承担边界与杠杆使用上限。 |
| **财务管理制度** (Financial Management System) | Financial Management System | 依据《会计法》《企业会计准则》及《山东省民间融资机构会计核算办法》建立的涵盖核算规范、收支管控、成本分摊与利润分配的全流程财务治理机制。 |
| **学习型组织** (Learning Organization) | Learning Organization | 民间资本管理公司为应对金融创新快速迭代与监管规则持续演进，通过制度化培训、知识共享与经验复盘构建的组织能力提升机制。 |
| **企业文化建设** (Corporate Culture Construction) | Corporate Culture Construction | 通过统一视觉识别、行为规范与价值倡导（如审慎、专业、服务实体），塑造机构公信力与员工职业认同，支撑长期稳健经营的软性基础设施。 |
| **实体经济项目** (Real Economy Projects) | Real Economy Projects | 民间资本管理公司资金投向必须聚焦农业、制造业、小微企业等非金融领域生产性活动，体现金融服务实体经济的根本定位与政策导向。 |
| **股东定向借款** (Shareholder-directed Loan) | Shareholder-directed Loan | 民间资本管理公司向特定股东筹集的、具有明确用途与期限约定的补充性资金，属监管认可的合法融资渠道，但需纳入统一风险管理体系。 |
| **流动性风险** (Liquidity Risk) | Liquidity Risk | 因短期财务性投资占比过高、资产久期错配或集中兑付压力，导致机构无法及时以合理成本变现资产或获得融资以履行支付义务的风险类型。 |
| **风险防火墙** (Risk Firewall) | Risk Firewall | 通过内控制度、财务制度与资产分类拨备等多重机制形成的系统性风险隔离屏障，旨在阻断操作风险、信用风险与市场风险的传导链。 |
| **规范化运营** (Standardized Operation) | Standardized Operation | 在监管框架下实现业务流程标准化、信息披露透明化、档案管理电子化、决策程序制度化的可持续经营模式。 |
| **资本实力** (Capital Strength) | Capital Strength | 综合反映民间资本管理公司注册资本规模、实缴资本到位率、净资产充足率及资本补充能力的核心监管指标，直接关联其风险承载力与评级等级。 |
| **合规经营** (Compliance-based Operation) | Compliance-based Operation | 严格遵循《山东省地方金融条例》《民间融资机构监督管理办法》等法规规章，在业务准入、资金投向、信息披露、关联交易等方面保持持续合法性的基本经营底线。 |

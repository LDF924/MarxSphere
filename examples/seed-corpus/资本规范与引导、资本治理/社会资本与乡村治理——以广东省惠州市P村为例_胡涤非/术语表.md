# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **社会资本** (Social Capital) | Social Capital | 指嵌入于社会关系网络中的实际或潜在资源集合，以信任、互惠规范和公民参与网络为基本维度，能够促进集体行动、提升治理效能并降低交易成本；本文特指乡村社区中基于血缘、地缘与业缘形成的结构性关系资源及其治理功能。 |
| **乡村治理** (Rural Governance) | Rural Governance | 指在乡村场域中多元主体（村民、村两委、乡镇政府、社会组织等）依据制度规则与非正式规范，协同提供公共产品、调解矛盾冲突、参与公共事务决策的过程；本文强调其有效性取决于本地化社会资本的丰裕程度与结构质量。 |
| **横向信任** (Horizontal Trust) | Horizontal Trust | 指村民之间基于熟人社会、亲缘地缘纽带形成的水平方向人际信任，体现为对本村村民行为可预期性与道德可靠性的普遍认同，是乡村内生合作与互助的基础性社会资本。 |
| **纵向信任** (Vertical Trust) | Vertical Trust | 指村民对村级组织（村委会）及上级政府（乡镇、县市）等垂直权力主体的信任程度，反映基层政权合法性与公信力，本文揭示其呈现‘村委会高—乡镇政府低’的倒U型梯度分布特征。 |
| **互惠规范** (Norms of Reciprocity) | Norms of Reciprocity | 指乡村社会中被广泛认可并实践的给予与回报行为准则，分为均衡互惠（即时对等交换）与普遍化互惠（延迟性、扩散性回报预期），后者构成集体行动可持续性的核心制度基础。 |
| **公民参与网络** (Civic Engagement Network) | Civic Engagement Network | 指村民基于共同利益、历史记忆与文化认同自发形成的横向联结组织形态（如宗族、邻里互助圈、红白理事会等），具有自我强化、监督惩戒与动员协调功能，是社会资本的空间载体。 |
| **亲缘网络** (Kinship Network) | Kinship Network | 以血缘和婚姻关系为轴心构建的社会支持系统，包括家庭圈、共房、宗族等层级，在P村表现为生产经营、红白喜事与紧急事件中首选的合作单元，兼具情感性与工具性双重属性。 |
| **地缘互助网络** (Territorial Mutual-Aid Network) | Territorial Mutual-Aid Network | 依托村落地理边界与长期共居历史形成的邻里互助关系体系，虽随人口流动与个体化增强而弱化，但仍承担日常照护、信息传递与社区整合功能，是乡村社会资本的空间锚点。 |
| **宗族网络** (Clan Network) | Clan Network | 以父系世系为纽带、涵盖共房与同姓家族的扩展型亲属组织，在P村未形成强势宗族势力，但在经济支持、精神慰藉与仪式活动中仍发挥结构性支撑作用。 |
| **田野调查** (Fieldwork) | Fieldwork | 本研究采用的质性研究方法，通过在P村开展入户问卷调查（N=80）、开放式深度访谈（n=21）及乡镇部门半结构化访谈，获取第一手社会资本感知与行为数据，强调情境嵌入性与主位理解。 |
| **信任维度** (Trust Dimension) | Trust Dimension | 帕特南社会资本三元框架中的核心构成，本文将其操作化为横向（村民间）与纵向（干群间）两个子维度，用以测量乡村社会关系的黏合强度与治理信任基础。 |
| **规范维度** (Norms Dimension) | Norms Dimension | 指内化于乡村日常生活实践中的非正式制度，包括人情面子、礼俗规矩、借贷赊欠惯例等，构成约束投机行为、维系合作预期的隐性治理机制。 |
| **网络维度** (Network Dimension) | Network Dimension | 指社会资本的结构性载体，本文分解为家庭关系网络、宗族网络、地缘互助网络与民间组织网络四类，用以刻画乡村社会联结的密度、广度与异质性。 |
| **嵌入性理论** (Embeddedness Theory) | Embeddedness Theory | 本文隐含的理论视角，强调经济与政治行为深嵌于特定社会关系网络之中，乡村治理绩效不能脱离其本土化的信任结构、互惠传统与网络形态来理解。 |
| **利益联结机制** (Interest-Linkage Mechanism) | Interest-Linkage Mechanism | 指在P村社会资本实践中，互助选择并非单纯依血缘亲疏，而是受现实利益权衡驱动的动态过程，体现先赋身份与后致利益的交互建构特征。 |
| **村庄共同体** (Village Community) | Village Community | 本文分析的基本单位，指具有共同地域、历史记忆、文化认同与互动频次的社会实体，其内部社会资本存量直接决定集体行动能力与治理韧性。 |
| **干群关系** (Cadre-Peasant Relationship) | Cadre-Peasant Relationship | 乡村治理中关键的政治社会关系，本文将其置于纵向信任框架下考察，揭示乡镇干部行政失信导致的信任赤字及其对基层治理合法性的侵蚀效应。 |
| **公共事务参与** (Participation in Public Affairs) | Participation in Public Affairs | 村民通过村民会议、一事一议、监督村务等方式介入村庄公共决策的行为表征，本文视其为社会资本网络维度活跃度与规范维度内化程度的外显指标。 |
| **社会支持** (Social Support) | Social Support | 社会资本的功能性产出，本文操作化为经济支持（资金、劳力、物资）与精神支持（情感慰藉、价值认同）两类，用以测度不同网络类型的实际效用强度。 |
| **社会资本量化分析** (Quantitative Analysis of Social Capital) | Quantitative Analysis of Social Capital | 本文方法论创新点，通过设计多维度李克特量表与多项选择题，将抽象的社会资本概念转化为可统计的信任频率、网络规模、规范遵从度等可观测变量。 |
| **转型村庄** (Transforming Village) | Transforming Village | 本文案例P村的类型学定位，指处于农业主导向工商业主导转型进程中的行政村，其社会资本结构面临传统纽带弱化与新型关系重构的双重张力。 |
| **基层政权公信力** (Credibility of Grassroots Government) | Credibility of Grassroots Government | 乡镇政府在村民认知中履行承诺、公正行事与回应诉求的可信程度，本文发现其因政策执行偏差与腐败感知而严重受损，构成纵向信任塌陷的核心成因。 |
| **人情面子** (Renqing and Mianzi) | Renqing and Mianzi | 中国乡村特有的互惠文化实践形式，作为普遍化互惠规范的具象表达，既维系社会团结又可能异化为负担性义务，体现社会资本的双刃剑特性。 |
| **集体行动困境** (Collective Action Dilemma) | Collective Action Dilemma | 本文理论关切的核心问题，指村民在缺乏信任、规范与网络支撑时难以克服搭便车动机以达成公共目标（如修路、抗灾、环境治理），凸显社会资本的治理解困功能。 |
| **本土化适应** (Localization Adaptation) | Localization Adaptation | 指将帕特南西方社会资本理论应用于中国乡村语境时，对其信任生成逻辑（血缘优先）、网络形态（宗族/地缘复合）、规范载体（人情礼俗）所作的实质性调适与再诠释。 |

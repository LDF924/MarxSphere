# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **地方法人金融机构** (Local Legal-Entity Financial Institutions) | Local Legal-Entity Financial Institutions | 指依法在地方设立、具有独立法人资格的银行类金融机构，包括农村信用社、村镇银行等，其资本构成、治理结构和监管归属受地方政府与中央金融监管部门双重影响。 |
| **资本构成** (Capital Composition) | Capital Composition | 指金融机构自有资本的来源结构与形式构成，包括实收资本、资本公积、盈余公积、一般风险准备、未分配利润及附属资本等，直接决定其资本充足性与风险抵御能力。 |
| **实收资本** (Paid-in Capital) | Paid-in Capital | 股东实际缴纳并经验资确认的出资额，是地方法人金融机构核心资本的基石，在本文中特指农村信用社和村镇银行已到位的股本金，反映资本真实性和出资履约情况。 |
| **资本充足率** (Capital Adequacy Ratio (CAR)) | Capital Adequacy Ratio (CAR) | 监管核心指标，指资本净额与加权风险资产总额之比，用于衡量机构抗风险能力；文中庆阳农信社资本充足率下降7.65个百分点，凸显资本扩张滞后于风险资产过快增长。 |
| **核心资本充足率** (Tier 1 Capital Ratio) | Tier 1 Capital Ratio | 核心资本（实收资本、资本公积、盈余公积、未分配利润等）与加权风险资产之比，体现高质量资本对风险的覆盖能力；村镇银行该指标为17.06%，高于其整体资本充足率，说明附属资本占比低且质量受限。 |
| **三会制度** (Three-Meeting Governance System) | Three-Meeting Governance System | 指农村信用社改革中确立的社员（代表）大会、理事会、监事会制度，构成现代法人治理基本框架；文中指出其‘流于形式’，暴露治理结构虚化与决策制衡失效问题。 |
| **不良贷款** (Non-Performing Loans (NPLs)) | Non-Performing Loans (NPLs) | 按四级分类标准认定的逾期、呆滞、呆账贷款，文中以绝对额与占比双升（+68.56%、+3.44个百分点）揭示资本损耗与拨备缺口并存的系统性风险。 |
| **拨备计提** (Provisioning for Loan Losses) | Provisioning for Loan Losses | 金融机构依据监管要求和审慎原则，从利润中提取用于弥补预期信用损失的准备金；文中‘常年计提不足’直指资本内生补充机制失灵。 |
| **存贷比** (Loan-to-Deposit Ratio) | Loan-to-Deposit Ratio | 各项贷款余额与各项存款余额之比，反映资金运用效率；庆阳农信社存贷比72%、存差19.17亿元，表明资本未能有效转化为生产性信贷投放。 |
| **高流动性资产** (Highly Liquid Assets) | Highly Liquid Assets | 可迅速无损变现的资产（如超额准备金、国债等），文中高达20.07亿元、占比28.32%，折射资本配置低效与盈利模式单一问题。 |
| **增资扩股** (Capital Increase and Share Expansion) | Capital Increase and Share Expansion | 通过新增股东出资或原股东追加投资扩充实收资本的行为，是改善资本构成、提升资本充足率的关键路径；文中指出其‘进展缓慢’，反映产权改革与市场化融资机制尚未激活。 |
| **附属资本** (Tier 2 Capital) | Tier 2 Capital | 包括一般风险准备、次级债等补充性资本工具，质量低于核心资本；村镇银行附属资本仅200万元，占比较小，凸显资本结构刚性与风险缓冲能力薄弱。 |
| **风险补偿机制** (Risk Compensation Mechanism) | Risk Compensation Mechanism | 针对特定业务风险（如涉农贷款自然灾害风险）建立的保险、财政贴息、再担保等分担制度；文中指出其‘不健全’，导致信用风险向金融机构单向转嫁。 |
| **第一责任人制度** (Primary Responsibility System) | Primary Responsibility System | 将合规经营、风险防控等关键职责明确到具体岗位与人员，并实行问责追溯的内部治理机制；文中将其作为内控建设的核心抓手。 |
| **工效挂钩考核** (Performance-Based Remuneration System) | Performance-Based Remuneration System | 将员工薪酬与信贷资产质量、清收绩效等量化指标直接关联的激励机制，旨在矫正道德风险与逆向选择，强化资本使用责任意识。 |
| **置换不良贷款** (Replaced Non-Performing Loans) | Replaced Non-Performing Loans | 指通过央行票据兑付等方式将历史不良贷款从账面剥离但管理责任仍由原机构承担的特殊资产，文中强调其清收进度滞后，构成隐性资本侵蚀风险。 |
| **资本净额** (Net Capital) | Net Capital | 核心资本与附属资本之和减去扣减项后的余额，是计算资本充足率的分子基础；庆阳农信社资本净额增长28%但增速远低于风险资产82.8%增幅，暴露资本消耗加速问题。 |
| **加权风险资产** (Risk-Weighted Assets (RWA)) | Risk-Weighted Assets (RWA) | 依据不同资产风险权重计算得出的总资产加权值，是资本充足率分母；其异常高增长（+82.8%）表明信贷扩张未匹配相应资本支撑。 |
| **农村信用社改革** (Rural Credit Cooperative Reform) | Rural Credit Cooperative Reform | 以产权明晰化、治理现代化、经营商业化为目标的系统性制度重构，文中‘三会’落实不力与观念转变滞后，折射改革深水区的体制惯性阻力。 |
| **涉农贷款** (Agriculture-Related Loans) | Agriculture-Related Loans | 投向农户、农业生产经营主体及农村基础设施的信贷资金，具有政策性、普惠性与高风险特征；村镇银行此类贷款占比高，但缺乏配套风险分担机制。 |
| **超额存款准备金率** (Excess Reserve Ratio) | Excess Reserve Ratio | 金融机构存放于央行的超过法定要求的准备金占存款总额比重；文中平均达34.77%，反映资金沉淀严重与资本运用能力不足。 |
| **信贷资产质量清理** (Credit Asset Quality Review) | Credit Asset Quality Review | 通过内部排查纠正贷款形态分类失真、隐匿不良等问题的专项治理行动；文中将其列为不良贷款‘真实暴露’的重要动因，体现监管趋严下的数据纠偏过程。 |
| **资本要素配置效率** (Capital Factor Allocation Efficiency) | Capital Factor Allocation Efficiency | 衡量资本在金融机构内部是否被有效转化为服务实体经济的信贷供给与盈利能力，文中存贷比偏低、高流动性过剩即为其低效的实证表现。 |
| **法人治理有效性** (Effectiveness of Corporate Governance) | Effectiveness of Corporate Governance | 指‘三会一层’制度能否实质性发挥决策制衡、监督约束与战略引领功能；文中指出其‘观念与形式不统一’，揭示形式合规与实质治理的结构性脱节。 |
| **资本监管合规性** (Capital Regulatory Compliance) | Capital Regulatory Compliance | 金融机构资本构成、充足水平及变动情况持续符合《商业银行资本管理办法》等监管规则的程度；全文对策均围绕提升该合规性展开，体现强监管语境下的整改逻辑。 |

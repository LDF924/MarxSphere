# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **三保** (Three Guarantees) | Three Guarantees | 指基层政府必须优先保障的三项基本民生支出：保基本民生、保工资、保运转，是中央财政对地方财政运行底线管理的核心政策要求，具有刚性约束和优先支付序位。 |
| **码上监督平台** (QR-Code-Based Supervision Platform) | QR-Code-Based Supervision Platform | 宜春市推行的数字化财政监督系统，通过二维码技术实现公务接待等财政支出凭证的线上公开、实时核验与痕迹留痕，属‘阳光财政’在基层治理中的技术嵌入型监管创新。 |
| **六单核证制度** (Six-Document Verification System) | Six-Document Verification System | 公务接待报销必须同步提供六类法定凭证（公务接待公函、审批表、消费账单、转账凭证、记账票据、平台公开凭单）的闭环审核机制，体现财政支出‘事前审批—事中留痕—事后公开’的全链条控制逻辑。 |
| **PPP项目** (Public-Private Partnership Project) | Public-Private Partnership Project | 政府与社会资本基于合同关系合作提供公共产品或服务的模式，在本文语境中特指纳入全国PPP综合信息平台管理、接受财政全生命周期监管的规范化基础设施与公共服务项目。 |
| **财政承受能力红线** (Fiscal Affordability Red Line) | Fiscal Affordability Red Line | 指地方政府每一年度全部PPP项目支出责任不得超过一般公共预算支出10%的法定上限，是防范隐性债务风险、保障财政可持续性的刚性约束指标。 |
| **全生命周期财政监督** (Whole-Life-Cycle Fiscal Supervision) | Whole-Life-Cycle Fiscal Supervision | 覆盖PPP项目识别、准备、采购、执行、移交各阶段的动态化、过程性财政监管机制，强调绩效挂钩、风险预警与整改闭环，区别于传统的事后审计式监督。 |
| **绩效评价指标分类推进** (Categorized Performance Evaluation Indicators) | Categorized Performance Evaluation Indicators | 针对结构复杂、功能分区明确的PPP项目（如高铁站南北广场），按物理空间或功能模块分别设计差异化绩效指标体系，实现精准化、场景化绩效管理。 |
| **法律顾问全生命周期制度** (Whole-Life-Cycle Legal Counsel System) | Whole-Life-Cycle Legal Counsel System | 要求PPP项目公司聘请常年法律顾问，全程参与合同履约、争议调解、合规审查与风险处置，将法治保障嵌入项目投资、建设、运营、移交全过程。 |
| **预算一体化系统** (Integrated Budget Management System) | Integrated Budget Management System | 国家统一部署的数字化预算管理平台，支持对‘三保’等重点支出进行标签化标记、动态监控、异常预警和执行分析，是财政治理现代化的技术基础设施。 |
| **库款预测与调度** (Treasury Cash Forecasting and Allocation) | Treasury Cash Forecasting and Allocation | 基层财政部门按月开展国库现金流量预测，并通过银行协调、上级沟通、资金调度等方式保障‘三保’刚性支出及时足额兑付的动态平衡机制。 |
| **紧日子** (Tight-Budget Governance) | Tight-Budget Governance | 新时代财政管理理念，强调厉行节约、压减非刚性非重点支出、盘活存量资金资产，以提升财政资源统筹能力和抗风险韧性。 |
| **铁公鸡** (Stingy Steward) | Stingy Steward | 基层财政干部自我定位的廉政话语表达，喻指严控支出、精打细算、拒绝铺张浪费的刚性预算执行作风。 |
| **铁算盘** (Iron Abacus) | Iron Abacus | 象征财政部门科学精细理财能力的形象化术语，指依托数据分析、制度刚性与技术手段实现收支精准匹配与风险可控的现代财政治理能力。 |
| **财政支出责任台账** (Fiscal Expenditure Liability Ledger) | Fiscal Expenditure Liability Ledger | 对PPP项目未来年度政府付费、补贴、绩效奖励等财政支出义务进行逐项登记、动态更新、滚动测算的法定管理工具，是落实财政承受能力监管的基础载体。 |
| **阳光运行** (Sunshine Operation) | Sunshine Operation | PPP项目监管的核心价值导向，强调信息公开（平台披露）、流程透明（程序合规）、结果可溯（绩效公开）、社会可监督，旨在防范权力寻租与暗箱操作。 |

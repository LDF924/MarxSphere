# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **差序格局** (Differential Mode of Association) | Differential Mode of Association | 源自费孝通《乡土中国》的社会关系结构理论，在本文中被类比用于描述上市公司财务造假所涉主体间以‘双控人’为中心、依亲疏远近与控制力强弱分层嵌套的责任与共谋关系网络，体现为‘双控人—董监高—中介机构—供应商/客户/金融机构’的圈层化生态位结构。 |
| **双控人** (Controlling Shareholder and Actual Controller) | Controlling Shareholder and Actual Controller | 指上市公司的控股股东与实际控制人，是财务造假行为的主要组织者、指使者和最终受益者；本文强调其在差序格局中处于第一圈层核心地位，并因新证券法、刑法修正案（十一）及新公司法确立了行政、刑事与民事三重连带责任机制。 |
| **影子董事** (Shadow Director) | Shadow Director | 指虽未 formally 担任董事职务，但通过指示、干预等方式实际支配董事会决策的控股股东或实际控制人；新公司法第一百九十二条首次将其纳入法定责任主体，要求其与董事承担连带赔偿责任。 |
| **事实董事** (De Facto Director) | De Facto Director | 指不具有董事名义但实际执行公司事务、行使董事职权的控股股东或实际控制人；新公司法第一百八十条第三款明确其须履行忠实义务与勤勉义务，填补法律对隐性治理主体的规制空白。 |
| **过错推定责任** (Presumption of Fault Liability) | Presumption of Fault Liability | 新证券法第八十五条确立的民事归责原则，规定‘双控人’就信息披露违法承担连带赔偿责任，除非其能自证无过错；显著降低投资者举证负担，强化对首恶的民事追偿效力。 |
| **直接责任与终局责任** (Direct Liability and Ultimate Liability) | Direct Liability and Ultimate Liability | 最高法虚假陈述规定第二十条创设的二元责任结构：前者允许投资者直接起诉‘双控人’索赔；后者指上市公司赔偿后可向‘双控人’追偿全部损失，确保违法成本由真正责任人最终承担。 |
| **股东代位诉讼** (Shareholder Derivative Suit) | Shareholder Derivative Suit | 中小股东为维护公司整体利益，以自己名义代表公司对损害公司利益的董监高、实控人等提起的诉讼；本文以威创股份案为例，指出科学城集团作为持股超10%的非投服中心股东发起代位诉讼，标志该机制正从示范走向常态化。 |
| **资格罚** (Qualification Penalty) | Qualification Penalty | 监管机关对证券服务机构及其从业人员采取的限制从业资格类处罚，如暂停业务资格、限制文件受理等；本文强调其较‘财产罚’更具威慑力，并通过交易所监管互认实现‘一处受罚、处处受限’的跨市场约束。 |
| **帮助侵权** (Aiding and Abetting Tort) | Aiding and Abetting Tort | 民法典第一千一百六十九条及最高法虚假陈述规定第二十二条所确认的法律责任形态，指供应商、客户、金融机构等明知财务造假仍提供虚假合同、回函、存款证明等配合行为，应与造假主体承担连带赔偿责任。 |
| **IPO协调人** (IPO Coordination Agent) | IPO Coordination Agent | 非发行人董监高或员工，但受实控人指使参与IPO过程关键环节（如体外资金循环、客户回函造假）的外部人员；华道生物案系首例对其予以纪律处分的实践，拓展了财务造假责任主体的认定边界。 |
| **信息披露义务人** (Information Disclosure Obligor) | Information Disclosure Obligor | 依法负有真实、准确、完整披露信息义务的主体，不仅限于上市公司本身，还包括重大资产重组中的交易对方（如九好集团）、实际控制人、董监高等；最高检解答强调须结合具体法规（如《重组办法》）动态识别其义务边界。 |
| **新证券法** (Securities Law (2019 Revision)) | Securities Law (2019 Revision) | 2020年3月1日施行的修订版《中华人民共和国证券法》，确立信息披露为核心、压实‘看门人’责任、强化民事赔偿与行政处罚联动的制度框架，是当前资本市场法治建设的基石性法律。 |
| **刑法修正案（十一）** (Criminal Law Amendment (XI)) | Criminal Law Amendment (XI) | 2021年3月1日施行的刑法修正案，重点加大对欺诈发行证券罪、违规披露罪及提供虚假证明文件罪的刑罚力度，并增设‘双控人’组织、指使犯罪的专款规定，实现行刑衔接与罪责升级。 |
| **最高法虚假陈述规定** (Provisions of the Supreme People's Court on Hearing Civil Compensation Cases Arising from False Statements in the Securities Market) | Provisions of the Supreme People's Court on Hearing Civil Compensation Cases Arising from False Statements in the Securities Market | 2022年1月22日施行的司法解释，系统重构证券虚假陈述民事责任认定规则，明确各层级责任主体的归责原则、因果关系要件与损失计算方式，是投资者私力救济的核心程序依据。 |
| **新公司法** (Company Law (2023 Revision)) | Company Law (2023 Revision) | 2024年7月1日施行的修订版《中华人民共和国公司法》，首次引入影子董事、事实董事制度，强化控股股东、实际控制人对公司治理的实质责任，并完善董事高管履职赔偿机制，与证券监管形成制度协同。 |
| **中证中小投资者服务中心** (China Securities Investor Protection Fund Co., Ltd. (Investor Service Center)) | China Securities Investor Protection Fund Co., Ltd. (Investor Service Center) | 证监会下属公益机构，专司支持中小投资者维权，通过示范诉讼、股东代位诉讼、持股行权等方式推动公司治理改善；本文视其为激活民事追责机制的关键制度杠杆。 |
| **财务造假生态圈** (Financial Fraud Ecosystem) | Financial Fraud Ecosystem | 指围绕上市公司财务造假形成的、具有结构性依赖与功能分工的多主体共生网络，涵盖策划者（双控人）、执行者（董监高）、背书者（中介机构）及配合者（客户/供应商/金融机构），呈现典型的差序格局特征。 |
| **看门人机制** (Gatekeeper Mechanism) | Gatekeeper Mechanism | 资本市场中由会计师事务所、律师事务所、保荐机构等中介机构承担的独立核查与专业把关职责；新证券法通过‘勤勉尽责’义务法定化与‘没一罚十’等严惩措施，强化其作为制度性防线的功能定位。 |
| **行刑衔接** (Administrative-Criminal Linkage) | Administrative-Criminal Linkage | 行政执法（证监会处罚）与刑事司法（公安机关侦查、检察院起诉、法院审判）之间的证据转化、线索移送与责任协同机制；本文指出刑法修正案（十一）与新证券法、新公司法共同构建了更严密的行刑衔接闭环。 |
| **示范性案例** (Exemplary Case) | Exemplary Case | 由投服中心选取典型案件提起诉讼并胜诉后，为同类纠纷提供裁判指引与维权范式，降低其他投资者诉讼门槛与成本；本文将其视为推动董监高责任觉醒与民事赔偿落地的关键路径。 |
| **三重责任体系** (Triple Liability System) | Triple Liability System | 本文提炼出我国针对‘双控人’构建的行政责任（新证券法罚款）、刑事责任（刑法修正案量刑升级）与民事责任（过错推定+直接/终局责任）三位一体的追责架构，体现对首恶‘零容忍’的制度逻辑。 |
| **监管互认** (Regulatory Mutual Recognition) | Regulatory Mutual Recognition | 沪深北三大交易所对纪律处分结果实行跨市场通报与效力延伸机制，如深交所作出的资格罚同步适用于上交所、北交所项目审核，打破监管分割，形成全市场统一惩戒威慑。 |
| **体外账户** (Off-Balance-Sheet Account) | Off-Balance-Sheet Account | 由实控人或其关联方控制、未纳入上市公司合并报表范围的资金账户，常用于虚构交易、循环走账、掩盖资金占用；华道生物案中‘IPO协调人’操控该类账户构成财务造假关键环节。 |
| **信息披露义务边界** (Boundary of Disclosure Obligation) | Boundary of Disclosure Obligation | 判断某一主体是否构成法定信息披露义务人的规范标准，需结合其在交易中的实质角色（如重大资产重组交易对方）、所涉法规的具体条款（如《重组办法》第四条）及监管实践综合认定，而非仅以企业性质或名义身份为据。 |
| **标本兼治** (Addressing Both Symptoms and Root Causes) | Addressing Both Symptoms and Root Causes | 本文提出的资本市场治理策略，既通过高压执法打击造假行为（治标），更依托制度供给（如影子董事责任、帮助侵权追责）重塑治理结构与激励相容机制（治本），体现系统性监管思维。 |

# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **产业集群** (Industrial Cluster) | Industrial Cluster | 指在特定地理区域内，以专业化分工和协作关系为基础，由大量相互关联的制造企业、配套服务商、研发机构及地方政府等主体构成的产业集合体；本文特指安徽当涂博望地区以刃具制造为核心的块状经济形态，具有高度本地化、家族化与产业链嵌入特征。 |
| **社会资本** (Social Capital) | Social Capital | 指嵌入于社会网络中的实际或潜在资源集合，以信任、规范、互惠期望和关系网络为载体，能够降低交易成本、促进信息扩散与知识溢出；本文强调其作为集群内非正式治理资源的功能性本质，区别于经济资本与人力资本。 |
| **治理机制** (Governance Mechanism) | Governance Mechanism | 指产业集群中依托社会资本所形成的、非正式与正式制度协同作用的协调与约束体系，核心包括信任机制与规范机制，用以替代或补充科层制与市场契约，实现企业间自发合作与机会主义抑制。 |
| **社会网络** (Social Network) | Social Network | 指产业集群内行为主体（企业家、员工、供应商、销售员、政府等）基于地缘、血缘、业缘建立的动态性、根植性、中心性与开放性的关系联结系统；本文将其划分为横向（家族/人际）、纵向（产业链）、外围（专业销售队）三类结构。 |
| **粘合型社会资本** (Bonding Social Capital) | Bonding Social Capital | 指以强联系（如亲属、同乡、熟人）为纽带形成的紧密型社会资本形态，强调内部认同与互惠义务，在博望集群中表现为家族主导、方言共享、高信任度的封闭式合作网络。 |
| **根植性** (Embeddedness) | Embeddedness | 指产业集群的经济活动深度嵌入地方社会结构、文化传统与制度环境之中，体现为企业家本地化率高（97.9%）、雇员本地占比81.8%、企业难以外迁等特征，构成社会资本生成与存续的结构性前提。 |
| **信任机制** (Trust Mechanism) | Trust Mechanism | 指产业集群中通过重复博弈、生存依赖与声誉积累三条路径构建的非正式信用体系，使企业间在承包、订货、结算等环节无需正式契约即可达成合作，显著降低监督与执行成本。 |
| **声誉途径** (Reputation Pathway) | Reputation Pathway | 指在信息高度透明的本地网络中，企业履约能力与道德品质通过非正式渠道快速传播并固化为集体认知，形成‘声誉即资产’的自我实施约束机制，对违约行为产生即时性市场惩罚。 |
| **群内规范** (Intra-cluster Norms) | Intra-cluster Norms | 指产业集群内部自发形成的非正式行为准则与制裁机制，包括基于习俗的惯例（如集体投资建厂）和惩罚机制（如信息共享导致的交易排斥），是对正式法律制度的重要补充。 |
| **网络治理** (Network Governance) | Network Governance | 指依托社会网络结构实现的多中心、自组织治理模式，通过信任与规范的交互作用，在无统一权威的前提下协调企业间关系，提升资源配置效率与创新协同水平。 |
| **强联系** (Strong Ties) | Strong Ties | 指基于血缘、地缘与长期互动形成的高频率、高情感投入、高互惠义务的人际联结，在博望集群中构成社会资本的主要来源，支撑信息快速扩散与高度信任。 |
| **产供销分离** (Separation of Production, Supply and Sales) | Separation of Production, Supply and Sales | 指博望特有的‘小企业+大市场’经营模式，即生产企业专注制造，由13000人专业化销售队伍承担市场开拓与客户对接，通过社会网络实现产销高效衔接。 |
| **飞毛腿销售团队** (‘Fei Maotui’ Sales Force) | ‘Fei Maotui’ Sales Force | 指博望本地形成的规模达13000人的专业化、乡土化、经验型营销群体，继承‘一本地图一双腿，一本合同一张嘴’传统，构成集群对外市场嵌入的关键社会资本载体。 |
| **关系治理** (Relational Governance) | Relational Governance | 指在中国家族型产业集群语境下，以人情、面子、声誉等关系性资源替代正式合约进行协调的治理方式，其有效性高度依赖于本地化社会网络与文化共识。 |
| **路径依赖性** (Path Dependence) | Path Dependence | 指博望刃具产业集群的社会资本形成受三代人历史实践、地域文化与制度惯性影响，早期集体创业、家族传承等行为模式持续塑造当前网络结构与治理逻辑。 |
| **制度供给滞后** (Institutional Supply Lag) | Institutional Supply Lag | 指区域正式制度（如金融支持、产权保护、公共服务）建设落后于产业发展需求，倒逼集群内生出以集体文化、习俗惯例为代表的非正式制度安排。 |
| **自我实施机制** (Self-enforcing Mechanism) | Self-enforcing Mechanism | 指集群内惯例与规范无需外部强制即可被普遍遵守的运行逻辑，源于重复博弈下的理性预期与声誉约束，如博望集体投资建厂习惯因长期正向反馈而稳定延续。 |
| **交易成本** (Transaction Cost) | Transaction Cost | 指企业间在搜寻、谈判、签约、监督与执行过程中产生的费用；本文强调社会资本通过信任与信息共享显著降低集群内部的交易成本，提升协作效率。 |
| **知识溢出** (Knowledge Spillover) | Knowledge Spillover | 指集群内企业通过非正式交流、人员流动与技术模仿等方式实现隐性知识的跨组织传递，其效率高度依赖于社会网络的开放性与信任密度。 |
| **块状经济** (Block Economy) | Block Economy | 指县域范围内以中小企业集聚、专业化分工和地域品牌为特征的区域经济形态，是浙江‘温州模式’与安徽博望刃具集群的典型实践表征。 |
| **乡土性** (Local Rootedness) | Local Rootedness | 指产业集群发展源于本地历史脉络与民间技艺传承（如博望三代刀具匠人），企业家、工人、文化符号均内生于地方，构成社会资本地域性特征的核心维度。 |
| **扎根性** (Geographic Stickiness) | Geographic Stickiness | 指企业一旦嵌入集群便因专用性资产投入、本地供应链依赖与文化适应成本而难以迁移，强化了网络稳定性与社会资本的沉淀效应。 |
| **重复博弈** (Repeated Game) | Repeated Game | 指集群内企业因长期共处同一地域而形成的多次交互关系，使短期欺骗收益小于长期合作收益，成为理性信任建立的博弈论基础。 |
| **非正式制度** (Informal Institutions) | Informal Institutions | 指集群中自发演化的习俗、惯例、行规与道德约束等不成文规则，与正式法律制度互补共治，在博望体现为集体创业传统与销售伦理。 |
| **社会资本治理** (Social Capital-based Governance) | Social Capital-based Governance | 指将社会资本作为核心治理资源，通过激活信任、规范与网络联结来协调集群内多元主体关系，实现自发秩序、风险共担与协同创新的治理范式。 |

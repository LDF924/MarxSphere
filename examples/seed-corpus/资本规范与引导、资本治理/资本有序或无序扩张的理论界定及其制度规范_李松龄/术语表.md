# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **资本有序扩张** (Orderly Capital Expansion) | Orderly Capital Expansion | 指以追求有偿占有超额剩余价值为动机、通过技术创新与生产率提升实现的资本扩张，其结果能发展社会生产力、增加社会财富并促进全体人民共同富裕，符合社会主义市场经济本质要求和制度规范的扩张形态。 |
| **资本无序扩张** (Disorderly Capital Expansion) | Disorderly Capital Expansion | 指以无偿占有绝对剩余价值或相对剩余价值为动机、依赖延长工时、压低工资、垄断定价或跨界套利等非生产性方式实现的资本扩张，其结果抑制生产力发展、加剧贫富分化、损害实体经济与社会公平，违背共同富裕目标的扩张形态。 |
| **超额剩余价值** (Surplus Surplus Value) | Surplus Surplus Value | 马克思政治经济学核心概念，指个别资本家通过采用新技术、新方法降低商品个别价值，仍按高于个别价值的社会价值（市场价格）出售商品所获得的差额利润；其形成具有社会性、竞争性与暂时性，属资本有偿占有的创新回报，构成资本有序扩张的理论基础。 |
| **绝对剩余价值** (Absolute Surplus Value) | Absolute Surplus Value | 通过延长工作日或提高劳动强度，在必要劳动时间不变条件下增加剩余劳动时间所生产的剩余价值，体现资本对活劳动的直接剥削关系，是资本无序扩张的重要逐利动因。 |
| **相对剩余价值** (Relative Surplus Value) | Relative Surplus Value | 通过缩短必要劳动时间（如降低生活资料价值）、相应延长剩余劳动时间而生产的剩余价值，虽以技术进步为条件，但其实质仍是资本无偿占有劳动者创造的价值，若脱离分配正义则易导向无序扩张。 |
| **劳动力资本化** (Labor Power Capitalization) | Labor Power Capitalization | 将劳动者劳动力视为可确权、可入股、可分红的生产性资本要素，并通过股份制安排使其参与剩余价值分配的制度创新，旨在实现‘劳动贡献归劳动者所有、资本贡献归资本所有者所得’，是抑制无序扩张、促进共同富裕的关键产权机制。 |
| **资本逐利动机的合理性** (Rationality of Capital's Profit-Motive) | Rationality of Capital's Profit-Motive | 论文提出的核心分析维度，指资本追求超额剩余价值的动机具有经济合理性与制度正当性，因其以技术创新为前提、以市场交换为形式、以有偿占有为特征；而追求绝对/相对剩余价值的动机则因无偿占有劳动成果而具剥削性与不合理性。 |
| **质量型/内涵式资本扩张** (Quality-Oriented / Endogenous Capital Expansion) | Quality-Oriented / Endogenous Capital Expansion | 以提升资本技术含量、优化要素配置效率、推动全要素生产率增长为特征的扩张路径，典型表现为智能化替代、绿色低碳投资与产业链升级，是资本有序扩张在实践层面的结构性表达。 |
| **数量型/外延式资本扩张** (Quantity-Oriented / Extensive Capital Expansion) | Quantity-Oriented / Extensive Capital Expansion | 依赖资本存量简单复制、劳动力规模扩张与资源粗放投入的扩张模式，不改变技术范式与组织效率，易导致产能过剩、环境污染与共同富裕滞后，构成无序扩张的主要实现形式。 |
| **资本市场机制完善** (Sound Capital Market Mechanism) | Sound Capital Market Mechanism | 指资本要素自由流动、资本价格灵敏反映稀缺性、资本竞争公平有序的制度状态，其核心是产权保护、公平竞争审查、反垄断执法与准入清单动态管理构成的全链条治理体系。 |
| **公平竞争审查制度** (Fair Competition Review System) | Fair Competition Review System | 中国为破除行政性垄断与市场壁垒而建立的政策前置性审查机制，要求各级政府制定涉及市场主体经济活动的规章、规范性文件等须进行公平竞争评估，是保障资本要素机会平等进入市场的基础性制度安排。 |
| **全链条资本治理体系** (Whole-Chain Capital Governance System) | Whole-Chain Capital Governance System | 涵盖事前引导（如市场准入清单）、事中防范（如穿透式监管、算法审计）、事后监管（如反垄断处罚、投资者赔偿）的闭环治理架构，体现习近平总书记提出的‘规范和引导资本健康发展’的系统性治理逻辑。 |
| **共同富裕** (Common Prosperity) | Common Prosperity | 中国特色社会主义本质要求与资本扩张评价的根本价值标尺，指在高质量发展中实现全体人民物质生活与精神生活双富裕，强调初次分配注重效率与公平统一、再分配强化调节功能、三次分配倡导自愿共享，构成区分资本有序/无序扩张的终极判准。 |
| **社会主义市场经济** (Socialist Market Economy) | Socialist Market Economy | 以公有制为主体、多种所有制共同发展为基本经济制度，市场在资源配置中起决定性作用、更好发挥政府作用的经济体制；本文将其作为资本有序扩张得以实现的制度母体，强调所有制创新（如劳动力资本化）对调和资本逻辑与社会主义目标的关键意义。 |
| **资本有机构成** (Organic Composition of Capital) | Organic Composition of Capital | 马克思提出的分析范畴，指不变资本（C）与可变资本（V）的比例（C/V），其提高反映技术密集度上升与劳动节约型增长；本文隐含运用该概念，将质量型扩张对应于有机构成提升，数量型扩张对应于有机构成停滞。 |
| **虚拟资本** (Fictitious Capital) | Fictitious Capital | 马克思政治经济学术语，指以股票、债券、衍生品等金融工具形式存在的、脱离实体生产过程的价值符号；本文特指互联网金融等脱离实体经济的资本形态，其过度扩张易引发系统性风险与无序扩张。 |
| **资本产权制度** (Capital Property Rights System) | Capital Property Rights System | 界定资本归属、使用、收益与处置权责的法律与制度安排，是资本市场机制运行的基础性制度；本文强调健全该制度需同步确认货币资本与劳动力资本的双重产权属性，方能支撑有序扩张。 |
| **所有制形式创新** (Innovation in Ownership Form) | Innovation in Ownership Form | 超越传统股份制与混合所有制改革，探索将劳动力资本化为劳动者股份、构建劳动—资本利益共同体的新型产权结构，旨在从根源上消解资本无偿占有剩余价值的制度基础，实现资本逻辑与社会主义目标的有机统一。 |

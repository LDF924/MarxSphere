# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **政府和社会资本合作（PPP）** (Public-Private Partnership (PPP)) | Public-Private Partnership (PPP) | 指在公共服务领域，政府与社会资本基于合同关系建立长期合作关系，由社会资本承担项目投资、建设、运营并承担相应风险，政府依据绩效考核结果支付对价，旨在提升公共服务供给质量与效率的制度安排。 |
| **隐性债务** (Hidden Local Government Debt) | Hidden Local Government Debt | 指地方政府在法定债务限额之外，通过融资平台公司、政府购买服务、PPP变相举债、违规担保等方式形成的、未纳入预算管理但实际由财政承担偿债责任的债务，构成重大财政金融风险隐患。 |
| **物有所值评价（VFM）** (Value for Money Assessment) | Value for Money Assessment | PPP项目决策前的核心评估程序，通过定性与定量分析比较PPP模式与政府传统采购模式在全生命周期成本、风险分担、效率提升等方面的综合效益，判断采用PPP是否更具经济性与可行性。 |
| **财政承受能力论证** (Fiscal Affordability Assessment) | Fiscal Affordability Assessment | 对PPP项目全生命周期内政府财政支出责任进行测算与评估，确保年度支出责任不超过本级一般公共预算支出10%的红线，是防范财政风险、保障财政可持续性的刚性约束机制。 |
| **政府付费模式** (Government Payment Model) | Government Payment Model | PPP项目回报机制之一，指政府依据合同约定和绩效考核结果，直接向项目公司支付可用性付费、运营维护付费或绩效付费；其适用须严格受限于财政支出责任占比（≤5%）等审慎条件。 |
| **使用者付费模式** (User Charge Model) | User Charge Model | PPP项目回报机制之一，指项目收入主要来源于终端用户（如水费、通行费、门票等）支付，强调‘谁受益、谁付费’原则，要求使用者付费比例实质性高于10%，以体现风险共担与市场化运营特征。 |
| **绩效挂钩付费机制** (Performance-Based Payment Mechanism) | Performance-Based Payment Mechanism | PPP项目核心契约安排，指政府付费必须与项目产出数量、质量、效率等可量化、可验证的绩效指标严格绑定，严禁通过降低考核标准等方式固化或提前锁定财政支出责任。 |
| **项目资本金** (Project Equity Capital) | Project Equity Capital | PPP项目公司中由股东以自有资金认缴并实缴的出资，须符合国家关于基础设施项目最低资本金比例规定（如港口、沿海及内河航运为20%，机场为25%等），禁止以债务性资金虚假出资。 |
| **阴阳合同** (Dual Contract Arrangement) | Dual Contract Arrangement | PPP实践中规避监管的违规操作，指政府方与社会资本另行签订与主合同内容相悖的补充协议，实质承诺固定回报、回购本金或兜底风险，导致项目异化为变相举债。 |
| **融资平台公司** (Local Government Financing Platform (LGFP)) | Local Government Financing Platform (LGFP) | 地方政府注资设立、承担政府融资职能的国有独资或控股企业；文件明确禁止其作为社会资本参与本级PPP项目，以防‘左手倒右手’、规避预算监管与风险隔离。 |
| **全国PPP综合信息平台** (National PPP Integrated Information Platform) | National PPP Integrated Information Platform | 财政部主导建设的PPP项目全生命周期信息管理系统，承担项目库管理、信息披露、统计监测、风险预警等功能，是实现‘公开透明’原则与社会监督的技术载体。 |
| **财政支出责任占比** (Fiscal Expenditure Responsibility Ratio) | Fiscal Expenditure Responsibility Ratio | 指某地区所有PPP项目年度财政支出责任占本级一般公共预算支出的比例，设定7%风险提示线与10%刚性红线，构成PPP项目入库与实施的核心财政约束指标。 |
| **规范运作** (Standardized Operation) | Standardized Operation | PPP高质量发展的基本前提，涵盖制度健全、清单管理、全生命周期监管、动态调整、绩效激励等维度，强调项目从识别、论证、采购到移交各环节均须依法依规、权责清晰、风险匹配。 |
| **诚信履约** (Good Faith Performance) | Good Faith Performance | PPP治理的关键原则，要求地方政府恪守契约精神，将合规PPP项目的财政支出责任依法纳入预算管理，并按合同约定及时足额支付，以稳定社会资本长期投资预期。 |
| **民营企业参与优先支持** (Preferential Support for Private Enterprises) | Preferential Support for Private Enterprises | 政策导向性术语，指在PPP项目推介、评审、融资支持与专项资金安排中，对信用良好、运营能力强的民营企业给予同等条件下优先准入与倾斜支持，旨在破除所有制歧视、激发市场活力。 |

# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **民间标会** (Rotating Savings and Credit Association (ROSCA)) | Rotating Savings and Credit Association (ROSCA) | 一种依托地缘、亲缘关系的非正式金融组织形式，由会头发起、若干会脚参与，按约定周期轮流出让资金使用权，兼具互助融资与高息理财功能，属我国传统民间信用互助机制。 |
| **倒会** (ROSCA Collapse) | ROSCA Collapse | 指民间标会因会头携款潜逃、资金链断裂或集体违约导致无法继续轮转兑付，造成全体会员本金严重损失甚至血本无归的系统性信用崩塌事件。 |
| **会头** (ROSCA Organizer) | ROSCA Organizer | 标会的发起人与实际组织者，享有首期无偿用款权，并承担召集会脚、收取会款、主持竞标、风险兜底等核心责任，其信用状况直接决定标会存续稳定性。 |
| **会脚** (ROSCA Participant) | ROSCA Participant | 标会中除会头外的普通参与者，通过定期缴纳会款获得轮候中标资格，前期中标者相当于借款人，后期中标者相当于出借人，权利义务依轮次动态转换。 |
| **每期会款** (Periodic Contribution) | Periodic Contribution | 每位会脚在每一期标会活动中须缴纳的固定金额，构成当期可分配资金池的基础，其数额通常由会首与会脚协商确定并写入书面协议。 |
| **总会款** (Total Pool Amount) | Total Pool Amount | 单期标会所有会脚缴纳的会款总额，即当期可供中标者一次性使用的全部资金，体现标会的规模效应与流动性承载能力。 |
| **理性标会** (Rational ROSCA) | Rational ROSCA | 符合利率上限（不超同期银行贷款基准利率4倍）、单期金额可控（≤1000元）、用途正当（生产生活消费）、周期合理（匹配真实资金需求）且具契约化管理特征的规范化民间互助金融形态。 |
| **非理性标会** (Irrational ROSCA) | Irrational ROSCA | 具有高利贷属性、短期高频运作、资金流向非生产性或非法领域（如赌博、奢侈消费、走私贩毒），且缺乏基本信用约束与法律保障的投机性、掠夺性民间金融活动。 |
| **地缘关系** (Geographical Embeddedness) | Geographical Embeddedness | 以同村、同乡等地理邻近性为基础形成的社会信任网络，构成民间标会组织动员、信用识别与风险约束的核心社会资本机制。 |
| **人缘关系** (Personal Relational Embeddedness) | Personal Relational Embeddedness | 基于亲属、朋友、邻里等私人情感纽带建立的信任基础，是标会成员筛选、履约监督及道德惩戒得以实施的社会性治理资源。 |
| **隐蔽价格** (Hidden Price) | Hidden Price | 指在利率管制背景下，正规金融体系因信贷配给、抵押门槛等因素形成的隐性融资成本溢价，成为民间标会高利率生存的结构性动因。 |
| **金融市场化滞后** (Financial Marketization Lag) | Financial Marketization Lag | 指我国金融服务供给未能同步于实体经济多元化融资需求，表现为中小微主体与农户信贷可得性低、产品适配性差、价格机制僵化等制度性短板。 |
| **基层金融治理** (Grassroots Financial Governance) | Grassroots Financial Governance | 乡镇、村级组织依法对辖区内民间金融活动开展登记备案、信用监测、风险预警与协同处置的属地化监管实践，是防范系统性金融风险的前沿防线。 |
| **民间资本合理利用** (Rational Utilization of Informal Capital) | Rational Utilization of Informal Capital | 在守住不发生系统性风险底线前提下，通过制度化引导将分散、自发的民间闲置资金纳入规范轨道，服务于乡村振兴、小微经营与民生改善的可持续金融路径。 |
| **标会登记备案制** (ROSCA Registration System) | ROSCA Registration System | 要求理性标会向乡镇政府或指定监管部门履行信息登记义务，包括会首资质、会员名单、协议文本、资金用途等要素，实现民间金融活动从‘地下’到‘台面’的可控转化。 |
| **信用记录共享机制** (Credit Information Sharing Mechanism) | Credit Information Sharing Mechanism | 跨部门（金融监管、工商、公安、税务）共建的标会参与主体负面信用数据库，通过信息互通限制失信会头重复组会，强化民间金融领域的声誉约束。 |
| **联合担保贷款** (Joint Liability Lending) | Joint Liability Lending | 针对农村信用缺失现实，由多户农户自愿组成联保小组，相互提供信用背书与连带偿债责任，降低金融机构风控成本与农户融资门槛的普惠金融创新模式。 |
| **金融知识普及** (Financial Literacy Promotion) | Financial Literacy Promotion | 面向农村居民开展的关于正规金融渠道、投资风险识别、合同权益保护及非法集资辨识的常态化宣传教育，是提升民间资本配置理性的基础性制度安排。 |
| **非正式金融制度** (Informal Financial Institution) | Informal Financial Institution | 未纳入国家金融监管体系、不依赖法定货币发行与存款保险机制、依靠社会规范与声誉机制维系运行的民间信用安排，标会为其典型代表。 |
| **利率管制** (Interest Rate Control) | Interest Rate Control | 国家对金融机构存贷款利率设定上限或浮动区间，虽具宏观调控功能，但易催生套利空间，为民间高利贷与标会利率畸高提供制度诱因。 |
| **田野调查** (Field Research) | Field Research | 研究者深入石狮市港塘村等典型村落，通过入户访谈、问卷调查与参与式观察获取一手数据，是本文识别标会运行逻辑与风险成因的核心实证方法。 |
| **制度缺位** (Institutional Vacuum) | Institutional Vacuum | 指现行法律体系未对民间标会的组织形式、契约效力、监管主体、责任边界作出明确规定，导致其游离于合法与非法之间，治理失序的根本症结。 |
| **利益联结机制** (Interest-Linkage Mechanism) | Interest-Linkage Mechanism | 标会中会头与会脚间通过资金周转、利息分配与信用捆绑形成的动态博弈结构，既具合作互惠性，也蕴含道德风险与逆向选择张力。 |
| **资本要素配置** (Capital Factor Allocation) | Capital Factor Allocation | 本文语境下特指民间闲散资本在城乡二元金融结构下，因正规渠道梗阻而自发流向标会等非正式领域的错配现象，反映要素市场化改革的深层矛盾。 |
| **乡村金融韧性** (Rural Financial Resilience) | Rural Financial Resilience | 指基层金融体系在应对标会崩盘等冲击时，通过预警响应、替代服务供给与社区修复能力维持基本融资功能与社会稳定的能力，是乡村振兴的重要支撑维度。 |

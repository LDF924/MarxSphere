| 术语 | 英文 | 释义 |
|------|------|------|
| **注册制** | Registration-based IPO System | 以信息披露为核心、以市场化为导向的股票发行制度，监管机构不对发行人投资价值作实质判断，而是通过严格的信息披露要求、事中事后监管和法律责任追究保障市场公平与投资者权益。 |
| **投资者保护** | Investor Protection | 资本市场基础性制度安排，指通过法律、监管、司法及自律机制保障投资者特别是中小投资者知情权、参与权、收益权与救济权，核心是提升其获得感、安全感与公平受偿能力。 |
| **特别代表人诉讼** | Securities Class Action by Investor Protection Institution | 依据新《证券法》第95条第三款设立的中国特色集体诉讼机制，由投保机构作为法定原告代表全体适格投资者提起诉讼，实行‘默示加入、明示退出’原则，显著降低维权门槛与成本。 |
| **信息披露** | Information Disclosure | 注册制下发行人向市场持续、真实、准确、完整、及时披露影响投资决策的重大信息的法定义务，是市场定价、风险识别与责任追究的基础前提。 |
| **资本市场的人民性** | People-Centered Nature of Capital Market | 监管工作坚持以人民为中心发展思想的根本立场，将1.9亿中小投资者权益保障置于核心位置，体现资本市场服务实体经济与共同富裕目标的政治属性与价值导向。 |
| **零容忍** | Zero Tolerance | 对欺诈发行、财务造假、内幕交易、操纵市场等严重违法行为依法从严从快查处，强化行政、民事、刑事立体追责，切实提高违法成本的监管执法原则。 |
| **建制度、不干预、零容忍** | Building Institutions, Non-Intervention, Zero Tolerance | 新时代资本市场监管理念的三大支柱，强调以法治化制度建设为根本、以市场机制运行为前提、以严格执法震慑为保障的治理逻辑。 |
| **多层次资本市场** | Multi-Tiered Capital Market | 涵盖主板、科创板、创业板、北交所、新三板、区域性股权市场等不同功能定位与准入标准的市场体系，旨在满足不同类型企业融资需求与投资者差异化风险偏好。 |
| **独立董事制度** | Independent Director System | 依据《公司法》及证监会规章设立的上市公司治理机制，旨在通过外部专业人士监督内部人控制、防范利益冲突、保障中小股东权益，其权责边界与履职保障正经历系统性重构。 |
| **看门人机制** | Gatekeeper Mechanism | 中介机构（如券商、会计师事务所、律师事务所）在注册制下承担核查验证、专业把关与勤勉尽责义务，对发行人信息披露质量负连带责任，是资本市场信用体系的关键枢纽。 |
| **康美药业特别代表人诉讼案** | Kangmei Pharmaceutical Securities Class Action | 我国首单特别代表人诉讼实践，判赔24.59亿元，确立了投保机构主导、大规模投资者集体获赔、压实中介机构连带责任的司法范式，标志投资者保护从制度设计走向实效落地。 |
| **新《证券法》投资者保护专章** | Special Chapter on Investor Protection in the Revised Securities Law (2020) | 2020年修订《证券法》增设第五章‘投资者保护’，首次系统性确立先行赔付、强制调解、代表人诉讼、现金分红约束等制度，实现投资者权利从宣示性条款向可诉可执行规则跃升。 |
| **适当性管理** | Suitability Management | 证券经营机构根据投资者风险承受能力、产品风险等级及匹配情况履行告知、警示与禁止销售高风险产品给不适格投资者的法定义务，是前端风险防控的核心制度。 |
| **公益机构代表诉讼** | Public Interest Litigation by Investor Protection Institutions | 由中证中小投资者服务中心等法定投保机构以公益目的发起的证券民事赔偿诉讼，突破传统诉讼主体资格限制，解决中小投资者‘集体行动困境’与‘理性冷漠’问题。 |
| **连带赔偿责任** | Joint and Several Liability | 在虚假陈述案件中，独立董事、中介机构等非直接造假方因未勤勉尽责而被法院判决就全部或部分损失与主责方承担共同清偿责任，体现过错推定与实质公平原则。 |
| **敬畏市场、敬畏法治、敬畏专业、敬畏风险** | Respect for Markets, Rule of Law, Professionalism, and Risks | 证监会提出的监管理念四重维度，强调尊重市场规律与主体自主性、坚守法治底线、依托专业能力研判、强化系统性风险识别与防控的综合治理思维。 |
| **融资功能完备** | Comprehensive Financing Function | 资本市场通过股权、债权、衍生品等多元工具，高效匹配资金供给与实体经济需求，尤其支持科技创新、绿色发展与中小企业成长的资源配置能力。 |
| **有活力、有韧性** | Vibrant and Resilient | ‘活力’指市场机制充分有效、创新动能持续释放、主体行为规范有序；‘韧性’指在内外部冲击下具备自我修复、风险缓释与功能稳定运行的能力，体现制度弹性与抗压水平。 |
| **实控人与董监高责任穿透** | Penetrating Liability for Actual Controllers and Directors/Officers | 在证券违法案件中，监管与司法不再仅追究表面签字人责任，而是穿透至实际控制人、关键决策者及未尽勤勉义务的董事高管，强化‘实质重于形式’的责任认定逻辑。 |
| **诉调对接机制** | Litigation-Mediation Linkage Mechanism | 法院与证券期货纠纷调解组织建立的在线协同平台，实现立案前委派调解、审理中委托调解与裁判后执行衔接，提升群体性证券纠纷化解效率与社会效果。 |

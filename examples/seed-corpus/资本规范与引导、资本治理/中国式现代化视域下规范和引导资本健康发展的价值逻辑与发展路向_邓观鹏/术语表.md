# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **中国式现代化** (Chinese Modernization) | Chinese Modernization | 在中国共产党领导下，立足社会主义初级阶段基本国情，以共同富裕为根本目标、以人的自由全面发展为价值归宿，坚持物质文明与精神文明相协调、人与自然和谐共生、走和平发展道路的现代化新形态；其核心特征在于制度逻辑上以‘人民逻辑’统摄‘资本逻辑’，实践路径上实现资本要素功能发挥与异化风险防控的辩证统一。 |
| **资本二重性** (Dual Nature of Capital) | Dual Nature of Capital | 指资本同时兼具生产要素属性（增值性）与生产关系属性（增殖性）的内在矛盾统一：前者体现为资源配置、技术整合与生产力促进功能，构成中国式现代化不可或缺的动能；后者表现为逐利本性驱动下的剥削倾向、权力渗透与社会关系异化，构成必须通过制度与价值规范加以约束的根本依据。 |
| **资本健康发展** (Healthy Development of Capital) | Healthy Development of Capital | 在社会主义市场经济条件下，资本在服从和服务于人民根本利益与国家发展战略前提下，依法依规参与资源配置、产业创新与民生改善，避免脱实向虚、无序扩张、垄断操纵及政治文化渗透，实现效率与公平、活力与秩序、增长与安全有机统一的发展状态。 |
| **资本权力化** (Capital Politicization) | Capital Politicization | 资本凭借其经济实力突破市场边界，通过政商勾结、利益输送、设租寻租等方式深度介入公共权力运行过程，导致公权力被资本逻辑俘获、政策制定偏向资本集团利益、公共资源分配失衡的政治风险现象，是中国式现代化必须防范的‘首要危险’之一。 |
| **权力资本化** (Power Commodification) | Power Commodification | 公职人员利用职权将公共权力转化为谋取私人资本收益的工具，表现为审批寻租、监管套利、资源变现等行为，形成官商利益闭环网络，侵蚀党的执政合法性基础，构成对政治安全与治理效能的系统性威胁。 |
| **人民逻辑** (People-Centered Logic) | People-Centered Logic | 中国式现代化的根本价值立场，强调发展为了人民、依靠人民、成果由人民共享，以满足人民美好生活需要为出发点和落脚点，在资本治理中体现为对资本逻辑的超越性统摄，确保资本始终作为服务人民福祉的手段而非目的。 |
| **资本逻辑** (Capital Logic) | Capital Logic | 以剩余价值最大化为根本驱动力的内在运行规律，表现为无限增殖冲动、市场自发扩张、利润优先导向及对劳动、技术、数据等要素的工具化支配，其自发性若缺乏规制将必然导致社会分化、生态破坏与意识形态风险。 |
| **有为政府** (Proactive Government) | Proactive Government | 在社会主义市场经济中，以维护人民根本利益为最高准则，通过科学规划、有效监管、精准调控与法治保障，主动防范资本无序扩张、纠正市场失灵、保障公平竞争、兜牢民生底线的治理主体，是实现资本健康发展的制度支撑与行动保障。 |
| **有效市场** (Efficient Market) | Efficient Market | 在法治化、规范化、透明化制度环境中，各类资本平等准入、公平竞争、优胜劣汰，充分发挥价格机制、供求机制与竞争机制优化资源配置功能的市场形态，其‘有效性’以服务人民需要与国家战略为根本尺度，而非单纯效率或利润指标。 |
| **制度优势** (Institutional Advantage) | Institutional Advantage | 中国特色社会主义制度所具有的系统性、稳定性与适应性优势，具体体现为党的领导制度、公有制为主体多种所有制共同发展、按劳分配为主体多种分配方式并存等制度安排，构成对资本逐利本性进行结构性规约与功能性引导的根本保障。 |
| **资本劣势** (Inherent Defects of Capital) | Inherent Defects of Capital | 资本内生的负外部性表现，包括但不限于：加剧贫富分化（马拉高尼效应）、诱发金融与数字领域脱实向虚、催生技术异化与劳动过载、侵蚀政治生态、俘获文化生产并消解主流价值观，需通过制度设计予以前置性防范与全过程治理。 |
| **数字资本** (Digital Capital) | Digital Capital | 依托算法、平台、数据与算力等新型生产资料形成的资本新形态，具有高度虚拟性、隐蔽性与支配性，通过算法专制、时间吸纳与空间殖民等方式重构劳动过程与价值分配，成为新时代资本增殖与异化风险的关键载体。 |
| **金融资本** (Financial Capital) | Financial Capital | 以货币资本循环为核心、脱离实体经济而自我增殖的资本形态，在中国式现代化语境下特指借道影子银行、杠杆嵌套、虚拟经济套利等方式规避监管、放大系统性风险的资本运作方式，是防范‘脱实向虚’的重点对象。 |
| **共同富裕** (Common Prosperity) | Common Prosperity | 中国式现代化的本质要求与根本目标，强调在高质量发展中通过初次分配、再分配与三次分配协同发力，既做大‘蛋糕’又分好‘蛋糕’，防止资本积累导致的阶层固化与区域失衡，确保全体人民共享发展成果。 |
| **资本治理** (Capital Governance) | Capital Governance | 中国共产党领导下的系统性制度实践，涵盖立场引领（人民逻辑）、制度建构（所有制与分配制度）、主体协同（有为政府与有效市场）、风险防控（资本权力化/权力资本化）四大维度，旨在实现资本要素功能最大化与异化风险最小化的动态平衡。 |
| **社会主义市场经济** (Socialist Market Economy) | Socialist Market Economy | 以公有制为主体、多种所有制经济共同发展为根基，以按劳分配为主体、多种分配方式并存为机制，以党的领导为根本保证的经济体制；其本质是运用市场机制配置资源的同时，以社会主义制度优势驾驭资本、矫正市场失灵、保障公平正义。 |
| **资本增殖** (Capital Accumulation) | Capital Accumulation | 资本作为生产关系的运动本质，即通过占有剩余劳动、延长相对劳动时间、技术替代与算法控制等方式持续扩大自身规模的过程，区别于中性‘增值’，凸显其内在剥削性与社会关系压迫性。 |
| **资本增值** (Capital Appreciation) | Capital Appreciation | 资本作为生产要素的功能性表现，指其在技术进步、组织创新与资源配置优化过程中提升全要素生产率、推动财富增长与民生改善的正向经济效应，是中国式现代化肯定资本积极作用的学理基础。 |
| **政商关系** (Government-Business Relationship) | Government-Business Relationship | 政治权力与资本权力互动的基本界面，中国式现代化要求构建‘亲清统一’的新型政商关系：‘亲’体现为政府主动服务市场主体、优化营商环境；‘清’强调权力运行公开透明、杜绝利益输送与权力寻租。 |
| **文化资本化** (Cultural Commodification) | Cultural Commodification | 资本逻辑向精神生产领域渗透的异化现象，表现为文化产业过度商业化、内容生产迎合流量逻辑、价值表达让位于消费主义叙事，导致主流意识形态弱化、民族精神稀释与价值信仰危机。 |
| **马拉高尼效应** (Marangoni Effect (in Capital Context)) | Marangoni Effect (in Capital Context) | 本文借用物理学概念隐喻资本集聚引发的财富极化现象：资本在数字与金融技术加持下加速向头部寡头汇聚，形成‘富者愈富’的自我强化循环，挤压中小资本生存空间，加剧区域、行业与群体间发展不平衡。 |
| **两个毫不动摇** (Two Unswerving Commitments) | Two Unswerving Commitments | 党和国家对基本经济制度的根本坚持，即毫不动摇巩固和发展公有制经济，毫不动摇鼓励、支持、引导非公有制经济发展；其实践指向是通过公有资本主导力与非公资本活力的协同，实现资本结构优化与风险可控。 |
| **资本下乡** (Capital Going to the Countryside) | Capital Going to the Countryside | 工商资本进入农业农村领域的典型实践形态，本文虽未直接展开，但作为资本渗入政治经济文化多维空间的重要切口，其健康与否直接关涉乡村产业振兴、农民增收与基层治理效能，需纳入资本治理整体框架审慎规范。 |
| **田野调查** (Fieldwork) | Fieldwork | 本文虽属理论思辨型论文，但其对资本权力化、数字劳动异化等现实问题的深刻剖析，建立在对中国基层政商互动、平台用工生态、县域金融实践等真实场景的经验感知基础上，体现马克思主义政治经济学‘从实践中来、到实践中去’的方法论自觉。 |
| **嵌入性理论** (Embeddedness Theory) | Embeddedness Theory | 本文隐含的分析框架之一，强调资本运行并非脱离社会关系的纯粹经济过程，而是深嵌于政治制度、文化价值与组织网络之中；中国式现代化的成功正在于通过制度嵌入与价值嵌入，将资本牢牢锚定于社会主义轨道。 |

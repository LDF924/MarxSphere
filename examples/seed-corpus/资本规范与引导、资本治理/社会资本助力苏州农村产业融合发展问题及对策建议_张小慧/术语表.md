# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **社会资本** (Social Capital) | Social Capital | 本文中特指区别于政府财政投资的、由民营企业、国有企业、外商企业及个人等非公共主体筹集并投入农业农村领域的市场化资金，强调其逐利性、流动性与治理风险并存的双重属性，是推动农村产业融合的关键要素但需规范引导。 |
| **农村产业融合发展** (Rural Integrated Industrial Development) | Rural Integrated Industrial Development | 以农业为基础延伸产业链、拓展产业功能、促进要素集聚与技术渗透，打破一二三产业边界，通过组织制度创新实现农业增值增效、农民增收和乡村活力提升的系统性发展路径，核心目标是让农民更多分享产业增值收益。 |
| **资本下乡** (Capital Going to the Countryside) | Capital Going to the Countryside | 指工商资本向农村地区流动并参与农业生产、加工、流通、服务等环节的投资行为，本文语境下兼具乡村振兴推动力与‘圈地’‘逐利失序’双重面向，需配套准入监管与利益联结机制。 |
| **利益联结机制** (Interest-Linkage Mechanism) | Interest-Linkage Mechanism | 指社会资本与农民、合作社等主体之间通过土地入股、劳务合作、订单收购、保底分红等方式建立的权责对等、风险共担、收益共享的契约化合作关系，是防范小农被挤出、保障农民分享增值收益的核心制度安排。 |
| **负面清单制度** (Negative List System) | Negative List System | 本文提出用于规制社会资本投资农村的监管工具，明确禁止或限制资本从事占用耕地、非农化开发、破坏生态、历史人文资源掠夺等行为，形成市场准入的底线约束与信用惩戒框架。 |
| **农民契约精神缺乏** (Lack of Farmers' Contractual Awareness) | Lack of Farmers' Contractual Awareness | 指农户在土地流转、订单农业等合作中单方面违约、随意毁约、选择性履约等行为，根源在于法治意识薄弱、合同执行保障缺位及信息不对称下的博弈弱势，构成社会资本投资稳定性的关键风险点。 |
| **小农挤出效应** (Smallholder Displacement Effect) | Smallholder Displacement Effect | 社会资本规模化、机械化、市场化运营倒逼农业生产方式转型过程中，因资本门槛、技术能力与市场渠道差异，导致传统小农户丧失生产资料控制权或退出产业链前端，加剧农村内部收入分化与社会结构断裂。 |
| **土地租赁关系不稳定** (Instability of Land Leasing Relations) | Instability of Land Leasing Relations | 指农户因政策预期不明、租金博弈心理及短期利益导向，普遍倾向签订3年以下短期流转合同，与农业投资周期长、见效慢的客观规律严重错配，构成社会资本长期投入的根本性制度障碍。 |
| **第六产业** (Sixth Industry) | Sixth Industry | 源自今村奈良臣提出的产业融合理念，指将第一产业（1）、第二产业（2）、第三产业（3）相乘得6，强调以农业为基核，贯通产加销、农文旅、科工贸全链条，实现价值倍增与主体共赢的农村产业组织形态。 |
| **融资难、融资贵** (Financing Difficulty and High Cost) | Financing Difficulty and High Cost | 本文特指社会资本投资农村产业时面临的信贷期限短（如‘农发通’仅3年）、额度低、抵押品不足、评估体系缺失等结构性金融约束，与农业长周期、低回报、高风险特性形成尖锐矛盾。 |
| **职业农民** (Professional Farmer) | Professional Farmer | 指具备现代农业技能、经营管理能力与市场意识，以农业为稳定职业并享有社会保障、教育培训等制度支持的新型农业经营主体，是破解人才缺口、实现资本与人力协同的关键载体。 |
| **标准化、品牌化建设** (Standardization and Branding Construction) | Standardization and Branding Construction | 针对社会资本参与农村产业存在的无序竞争与价格战问题，通过政府引导行业组织制定生产、服务、质量标准，培育区域公用品牌与企业自主品牌，提升产业附加值与市场议价能力。 |
| **社区直销店** (Community Direct-Sale Store) | Community Direct-Sale Store | 一种缩短流通链条的本地化销售模式，由社会资本投资运营，农民按统一品控标准供货，实现农产品直产直供社区，减少中间损耗，确保利润更多留存于本地农民。 |
| **双向入股** (Bidirectional Equity Participation) | Bidirectional Equity Participation | 指农民以土地经营权、劳动力或资金入股社会资本项目，同时社会资本以技术、品牌、渠道等要素反向入股合作社或村集体，构建双向赋权、动态平衡的利益共同体。 |
| **保底收益+按股分红** (Minimum Guaranteed Return + Equity-Based Dividend) | Minimum Guaranteed Return + Equity-Based Dividend | 一种兼顾公平与效率的利润分配机制，在保障农民基本收益前提下，按股权比例分享超额利润，并通过设定资本分红上限防止收益过度向资本倾斜。 |
| **田野调查** (Field Investigation) | Field Investigation | 本文研究方法基础，指研究者深入苏州常熟中泾村、吴中衙甪里村、西山镇、太仓半泾村等典型村落开展实地访谈、参与观察与案例追踪，获取社会资本与农民互动的一手实证资料。 |
| **政府职能整合** (Integration of Government Functions) | Integration of Government Functions | 针对农村产业融合涉及农业、文旅、环保、发改等多部门的碎片化管理现状，主张打破条块分割，建立跨部门协同机制与‘一站式’服务平台，强化政府规划统筹与服务供给能力。 |
| **农业全产业链** (Agricultural Full Industrial Chain) | Agricultural Full Industrial Chain | 中央一号文件提出的政策概念，指从育种、种植养殖、加工、仓储物流、品牌营销到休闲体验的完整价值链条，是农村产业融合发展的空间载体与绩效衡量基准。 |
| **农民增收** (Farmers' Income Increase) | Farmers' Income Increase | 本文的终极价值导向，强调社会资本参与必须以提升农民可支配收入为核心目标，尤其关注缩小城乡收入差距（苏州2021年城乡居民收入比为1.85）与增强农民在产业链中的议价能力。 |
| **社会资本盲目性** (Blindness of Social Capital Investment) | Blindness of Social Capital Investment | 指缺乏农业产业认知的社会资本跟风进入特色小镇、康养、生态农业等领域，忽视农业长周期、弱质性与政策敏感性，导致项目同质化、补贴套取与可持续性危机。 |
| **农民专业合作社** (Farmers' Professional Cooperatives) | Farmers' Professional Cooperatives | 本文中作为农民与社会资本对接的关键中介组织，但存在代理异化风险——部分合作社偏离‘合作制’本质，演变为经营者牟利工具，损害成员权益，亟需强化民主治理与财务透明监管。 |
| **土地流转风险基金** (Land Transfer Risk Fund) | Land Transfer Risk Fund | 本文提出的制度创新建议，指由政府、社会资本与村集体共同出资设立的专项基金，用于补偿因承租方违约、经营失败等导致的农民土地租金损失，筑牢土地权益保障底线。 |
| **嵌入性治理** (Embedded Governance) | Embedded Governance | 隐含于本文政策建议中的理论逻辑，指政府监管与服务必须深度嵌入农村社会网络、产权结构与文化惯习之中，避免简单套用城市化监管范式，强调规则适配性与基层协商韧性。 |
| **共同富裕** (Common Prosperity) | Common Prosperity | 本文的价值锚点与政策归宿，要求社会资本参与农村产业融合不能仅追求资本回报，必须通过利益联结、价值分配与能力建设，实质性提升农民在现代化进程中的获得感、尊严感与发展权。 |
| **乡村振兴** (Rural Revitalization) | Rural Revitalization | 国家战略总抓手，本文将其具象化为以产业融合为引擎、社会资本为动能、农民为主体、政府为保障的系统工程，强调‘产业兴旺’是根本，而资本必须服务于‘农民受益’这一本质目标。 |

# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **家庭农场** (Family Farm) | Family Farm | 以家庭成员为主要劳动力、以农业经营为基本收入来源、实行规模化标准化生产的新型农业经营主体，具有独立市场主体地位和自主决策权，是推进农业农村现代化和乡村振兴的关键载体。 |
| **订单生产经营行为** (Order-based Production and Operation Behavior) | Order-based Production and Operation Behavior | 家庭农场与合作社、龙头企业或采购商等签订契约性协议，按约定品种、数量、质量、价格和交付时限组织生产与交付的市场化经营行为，体现契约治理、风险共担与利益联结特征。 |
| **社会资本** (Social Capital) | Social Capital | 嵌入于社会关系网络中的资源总和，包括社会网络（结构维度）、社会信任（认知维度）和社会规范（制度维度）三重构成，通过非正式制度机制影响信息获取、风险分担与合作履约能力。 |
| **社会网络** (Social Network) | Social Network | 家庭农场主在村域内形成的由亲友、邻舍、村干部、农技员、收购商及合作社等构成的结构性关系集合，其规模与密度直接影响市场信息可及性与订单机会获取效率。 |
| **社会信任** (Social Trust) | Social Trust | 家庭农场主与交易伙伴（如合作社、企业、消费者）之间基于长期互动形成的非机会主义互信关系，是降低契约执行成本、增强订单合作韧性与稳定性的核心认知基础。 |
| **社会规范** (Social Norms) | Social Norms | 山区农村社区中被广泛认可并内化的非正式行为准则（如绿色生产、诚信履约、互助协作），通过‘羊群效应’和‘锁定效应’引导家庭农场主动调适经营行为以契合公共期待与政策导向。 |
| **知识存量** (Knowledge Stock) | Knowledge Stock | 家庭农场主经由教育培训、实践积累、经验模仿与技术扩散所内化的显性与隐性知识总和，构成其识别订单机会、理解契约条款、转化外部知识并创新经营方式的能力基础。 |
| **信息素养** (Information Literacy) | Information Literacy | 家庭农场主在订单农业情境下具备的信息意识、多渠道信息获取能力（如自媒体、政府平台、社会化服务组织）及将信息转化为生产决策与市场行动的实践能力。 |
| **中介效应** (Mediating Effect) | Mediating Effect | 知识存量与信息素养分别作为社会资本影响订单生产经营行为的传导路径变量，其部分中介效应表明社会资本需经由个体能力建设才能实质性转化为经营行为改变。 |
| **刺激—机体—反应（S-O-R）理论模型** (Stimulus-Organism-Response (S-O-R) Model) | Stimulus-Organism-Response (S-O-R) Model | 本研究采用的认知行为分析框架：将社会资本视为外部环境刺激（S），知识存量与信息素养表征个体认知与能力状态（O），订单生产经营行为则是可观察的响应结果（R）。 |
| **结构方程模型（SEM）** (Structural Equation Modeling (SEM)) | Structural Equation Modeling (SEM) | 一种融合测量模型与结构模型的多元统计方法，用于同时检验潜变量（如社会资本各维度）间因果路径及其对观测变量的影响强度，并支持中介效应的量化分解与显著性检验。 |
| **秦巴—武陵山区** (Qinba-Wuling Mountainous Area) | Qinba-Wuling Mountainous Area | 我国长江中上游连片特困区与生态屏障区，涵盖陕南、渝东北、鄂西、湘西四省市交界地带，具有地形破碎、交通受限、信息闭塞、产业基础薄弱等典型山区特征，构成本研究的特殊地域场域。 |
| **田野调查** (Field Survey) | Field Survey | 研究者深入秦巴—武陵山区22个县（区）开展实地访谈与问卷调查，结合定点入户与线上补充采集448份有效样本，确保数据扎根于真实乡村社会经济情境。 |
| **李克特五点量表** (Likert 5-point Scale) | Likert 5-point Scale | 本研究用于测量社会信任、社会规范、知识存量、信息素养及订单行为等潜变量的标准化测量工具，以‘非常不同意’至‘非常同意’或程度分级为锚点，保障量表信效度。 |
| **组合信度（CR）** (Composite Reliability (CR)) | Composite Reliability (CR) | 衡量潜变量内部一致性的指标，反映观测题项对同一构念的共同解释力，本研究中所有潜变量CR值均＞0.7，表明量表具有优良的结构信度。 |
| **收敛效度** (Convergent Validity) | Convergent Validity | 指同一潜变量下各观测题项能有效聚合反映该构念的程度，本研究通过标准化因子载荷＞0.6及校正项总相关性（CITC）＞0.4予以验证。 |
| **区别效度** (Discriminant Validity) | Discriminant Validity | 指不同潜变量之间具有足够区分度的属性，本研究通过各潜变量间Pearson相关系数显著但低于其各自AVE平方根值予以确认。 |
| **AMOS结构方程软件** (AMOS Structural Equation Modeling Software) | AMOS Structural Equation Modeling Software | IBM开发的图形化SEM分析工具，本研究采用其最大似然估计（MLE）法进行模型拟合、路径系数估计与中介效应Bootstrap检验。 |
| **路径标准化系数** (Standardized Path Coefficient) | Standardized Path Coefficient | 反映自变量对因变量直接影响强度的无量纲指标，本研究中社会信任（0.201）对订单行为影响最大，表明其在山区契约履约中具有核心枢纽作用。 |
| **部分中介作用** (Partial Mediation) | Partial Mediation | 知识存量与信息素养均未完全替代社会资本的直接影响，而是与社会资本共同作用于订单行为，证实社会资本既通过能力提升间接赋能，也存在直接制度性影响。 |
| **隐性知识** (Tacit Knowledge) | Tacit Knowledge | 家庭农场主通过师徒传承、邻里示范、现场观摩等方式习得的难以编码化、情境依赖性强的实践性知识，在绿色技术采纳与订单履约中发挥关键作用。 |
| **新型农业经营主体** (New Agricultural Operating Entities) | New Agricultural Operating Entities | 国家政策语境下指以家庭农场、农民合作社、农业企业等为代表的市场化、组织化、专业化农业经营组织形态，是构建现代农业经营体系的核心力量。 |
| **订单农业** (Contract Farming) | Contract Farming | 农业生产者与下游企业或合作社签订具有法律约束力的购销协议，约定产前投入、产中指导与产后收购条件的产业化经营模式，旨在降低市场风险、稳定产销关系。 |

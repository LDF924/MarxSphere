# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **民间资本** (Private Capital) | Private Capital | 指非国有、非政府控制的个人、家庭、民营企业及社会团体等主体所拥有的可投入生产性或金融性活动的自有资金，在本文中特指以非正规或准正规方式参与地方金融供给的市场化资本力量，是青海地区金融体系补充与结构性改革的关键变量。 |
| **民间金融** (Informal Finance) | Informal Finance | 指游离于国家法定金融监管体系之外、未纳入央行及银保监统一监管框架的资金融通活动，包括民间借贷、资金互助、私募融资等形态；本文强调其兼具内生性、草根性与高风险性，亟需通过制度化路径实现规范转化。 |
| **宽进入、严监管** (Liberal Entry, Strict Regulation) | Liberal Entry, Strict Regulation | 本文提出的民间资本准入治理原则，即在降低市场准入门槛、鼓励多元主体参与金融供给的同时，构建穿透式、动态化、分类分级的监管体系，确保风险可控与功能有效并重。 |
| **融资性担保机构** (Financing Guarantee Institutions) | Financing Guarantee Institutions | 经监管部门批准设立、以信用增信为核心功能、为小微企业和‘三农’提供贷款担保服务的准金融机构；本文指出其在青海民间资本主导下快速扩张，但存在资本金虚化、代偿能力弱等治理隐患。 |
| **小额贷款公司** (Microfinance Companies) | Microfinance Companies | 由自然人、企业法人或其他社会组织出资设立、不吸收公众存款、主要为小微企业和农户提供小额信贷服务的有限责任公司或股份有限公司；本文视其为民间资本向正规金融过渡的重要组织载体。 |
| **典当行** (Pawnshops) | Pawnshops | 以动产或财产权利质押为条件提供短期融资服务的特殊工商企业，属地方金融组织体系中的‘类金融机构’；本文将其列为民间资本主导的融资功能机构典型代表。 |
| **资金互助社** (Rural Credit Cooperatives (Self-organized)) | Rural Credit Cooperatives (Self-organized) | 由农民、农村小企业自愿入股组成、实行民主管理、主要为社员提供存贷款服务的合作制金融组织；本文特别援引海东兴乐、玉树富民等案例，强调其作为‘合作性民间金融’的制度创新价值。 |
| **非法集资** (Illegal Fund-raising) | Illegal Fund-raising | 未经国务院金融管理部门依法批准，以许诺还本付息为手段向社会不特定对象吸收资金的行为；本文将其界定为民间融资失范的主要风险出口与社会稳定的重大威胁源。 |
| **征信制度** (Credit Reporting System) | Credit Reporting System | 以采集、加工、共享信用信息为基础，支撑金融交易风险定价与履约约束的基础设施；本文强调其是弥合民间金融与正规金融信任鸿沟、降低交易成本的核心制度安排。 |
| **金融联结** (Financial Linkage) | Financial Linkage | 指正规金融机构（如银行）与民间金融组织（如小贷公司、担保公司）之间通过业务合作、风险分担、技术输出等方式建立的制度化协作关系；本文主张以此机制引导民间资本有序嵌入主流金融体系。 |
| **温州金融综改试验区** (Wenzhou Financial Comprehensive Reform Pilot Zone) | Wenzhou Financial Comprehensive Reform Pilot Zone | 2012年国务院批准设立的全国首个区域性金融改革试验平台，核心任务是规范民间金融、探索民间资本阳光化路径；本文将其作为青海构建民间资本登记管理机构的政策参照系。 |
| **民间资本登记管理机构** (Private Capital Registration and Supervisory Authority) | Private Capital Registration and Supervisory Authority | 本文建议在省级层面设立的专责机构，承担民间资本进入金融领域的准入审核、备案登记、动态监测、合规评估与风险预警等职能，是实现‘宽进严管’的操作枢纽。 |
| **互助性合作金融组织** (Mutual Cooperative Financial Organizations) | Mutual Cooperative Financial Organizations | 基于成员共同所有、民主管理、服务优先原则建立的非营利性金融实体；本文主张将符合条件的民间金融组织转型为此类组织，赋予其合法地位并纳入合作金融监管框架。 |
| **产业政策引导** (Industrial Policy Guidance) | Industrial Policy Guidance | 通过财政贴息、税收优惠、风险补偿等政策工具，引导民间资本流向符合国家宏观战略与区域发展重点的实体经济领域（如绿色能源、特色农牧业），避免脱实向虚与盲目投机。 |
| **田野调查** (Field Investigation) | Field Investigation | 本文采用的实证研究方法，通过对海南州、海东、海西等地企业与个体样本的实地访谈、问卷发放与交易数据采集，获取第一手民间融资运行特征与风险表现，构成政策建议的经验基础。 |

# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **多层次资本市场** (Multi-tiered Capital Market) | Multi-tiered Capital Market | 指由主板、创业板、科创板、新三板（全国中小企业股份转让系统）、区域性股权市场（四板）等不同层次构成的、功能互补、有机衔接的资本市场体系，旨在匹配不同类型企业的发展阶段与融资需求，以及差异化投资者的风险偏好与专业能力。 |
| **新三板** (National Equities Exchange and Quotations (NEEQ)) | National Equities Exchange and Quotations (NEEQ) | 中国证监会监管下的全国性证券交易场所，定位于服务创新型、创业型、成长型中小微企业的场外公开市场，具有挂牌准入包容性强、融资方式多元、制度创新试验属性突出等特点。 |
| **场外市场** (Over-the-Counter (OTC) Market) | Over-the-Counter (OTC) Market | 指非集中竞价、非交易所主导的证券交易市场，以协议转让、做市交易、集合竞价（基础层/创新层）为主要方式，强调市场化机制与适度监管，典型代表为新三板和区域性股权市场。 |
| **自上而下的制度设计** (Top-down Institutional Design) | Top-down Institutional Design | 指中国资本市场发展路径区别于欧美‘自然演进’模式，由国家顶层设计先行确立框架（如《证券法》修订、国务院文件部署），再逐层设立市场板块并配套规则，体现政府主导与规划驱动特征。 |
| **挂牌准入门槛** (Listing Admission Threshold) | Listing Admission Threshold | 新三板对企业挂牌设定的差异化准入标准（如基础层要求持续经营满两年、有持续经营能力；创新层增设净利润、营收增速、研发投入等量化指标），体现其包容性与分层管理逻辑。 |
| **投资者适当性管理** (Investor Suitability Management) | Investor Suitability Management | 针对新三板高风险特征实施的差异化投资者准入制度，要求个人投资者具备2年以上证券投资经验及500万元证券资产门槛，旨在匹配产品风险与投资者识别/承受能力。 |
| **做市交易** (Market Making Trading) | Market Making Trading | 新三板特有交易机制之一，由具备资质的券商作为做市商持续报出买卖价，提供流动性支持，增强价格发现功能，体现场外市场专业化中介服务特征。 |
| **转板机制** (Delisting and Up-listing Mechanism) | Delisting and Up-listing Mechanism | 新三板挂牌企业满足条件后可向沪深交易所申请转板上市的制度安排（如‘转板上市办法’），构成多层次资本市场间有机衔接的关键枢纽，强化市场梯次培育功能。 |
| **并购整合** (Mergers and Acquisitions (M&A)) | Mergers and Acquisitions (M&A) | 新三板企业借助股权公开化、估值显性化优势开展横向或纵向并购，实现资源整合与规模扩张，是场外市场发挥资源配置功能的重要路径。 |
| **金融改革试验田** (Pilot Field for Financial Reform) | Pilot Field for Financial Reform | 指新三板被赋予探索注册制理念、差异化信息披露、灵活融资工具（如定向发行、优先股、可转债）、自律监管等前沿制度的政策定位，承担资本市场基础性制度改革压力测试功能。 |
| **资源汇聚效应** (Resource Agglomeration Effect) | Resource Agglomeration Effect | 新三板通过制度吸引力集聚大量中小企业、私募基金（PE/VC）、券商、律所、会计师事务所等市场主体，形成专业化服务生态与资本对接网络，提升整体市场运行效率。 |
| **包容性制度体系** (Inclusive Institutional System) | Inclusive Institutional System | 指新三板在企业准入、信息披露、交易方式、融资工具等方面采取差异化、弹性化安排（如分层管理、负面清单制），兼顾规范性与发展性，适配中小微企业治理不完善、信息透明度低等现实约束。 |
| **直接融资** (Direct Financing) | Direct Financing | 企业通过发行股票、债券等金融工具直接从投资者获取资金的方式，新三板作为场外公开市场，是缓解中小企业‘融资难、融资贵’、优化金融供给结构的关键直接融资渠道。 |
| **后发优势** (Late-mover Advantage) | Late-mover Advantage | 新三板在建设中充分借鉴主板监管经验与区域性股权市场教训，规避重复试错，在制度设计、技术系统、风控体系等方面实现跨越式发展，体现制度学习与集成创新特征。 |
| **市场化金融生态** (Market-oriented Financial Ecosystem) | Market-oriented Financial Ecosystem | 以新三板为枢纽形成的、由多元主体参与、基于供需匹配与价格机制自发调节的投融资服务体系，强调自律管理、中介专业性和市场内生秩序。 |

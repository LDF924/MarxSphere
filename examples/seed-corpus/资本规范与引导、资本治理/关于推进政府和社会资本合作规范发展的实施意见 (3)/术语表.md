| 术语 | 英文 | 释义 |
|------|------|------|
| **告知承诺审批** | Notification and Commitment Approval System | 指行政机关在审批过程中，以企业书面承诺符合审批条件并承担相应法律责任为前提，直接作出审批决定的行政许可改革模式，强调事前简化程序与事后严格监管相结合。 |
| **政府和社会资本合作（PPP）** | Public-Private Partnership | 在公共服务和基础设施领域，政府与社会资本基于合同建立长期合作关系，由社会资本承担投资、建设、运营等全生命周期责任，并依据绩效获取合理回报的制度性安排。 |
| **物有所值评价（VFM）** | Value for Money Assessment | PPP项目决策前的核心评估工具，通过定性与定量方法比较PPP模式与传统政府采购模式在全生命周期成本、风险分配、效率提升等方面的综合效益，判断其是否具备经济合理性。 |
| **财政承受能力论证** | Fiscal Affordability Assessment | 对PPP项目未来年度财政支出责任进行测算与动态监测，确保其占本级一般公共预算支出比例不超过10%，是防范地方政府隐性债务风险的关键前置约束机制。 |
| **正负面清单** | Positive and Negative Lists | PPP规范管理中明确界定鼓励支持的领域（如补短板公益性项目）与禁止或限制的行为（如回购本金、固定回报、融资平台作为社会资本），构成政策边界与合规审查基准。 |
| **全生命周期管理** | Whole-Life Cycle Management | 覆盖PPP项目识别、准备、采购、执行、移交等各阶段的系统化治理框架，强调风险分担、绩效挂钩、动态调整与闭环监管。 |
| **能进能出动态调整机制** | Dynamic Entry-and-Exit Mechanism | 依托全国PPP综合信息平台，对入库项目实施常态化合规性审查与绩效监测，对不达标项目及时清退，破除‘入库即合规’误区的制度化纠错机制。 |
| **政府付费项目** | Government-Payment PPP Projects | 以政府直接付费为主要回报来源的PPP项目类型，须满足财政支出责任占比≤5%、竞争性采购、绩效挂钩等审慎条件，严防异化为变相举债工具。 |
| **使用者付费比例** | User-Fee Ratio | PPP项目中来源于终端用户直接付费的收入占项目总收入的比例，文件规定低于10%且内容无实质关联的打包项目不予入库，旨在识别规避监管的‘伪市场化’操作。 |
| **阴阳合同** | Dual-Contract Arrangement | 政府方与社会资本私下签订与公开合同内容相悖的补充协议，用以规避财政监管、固化支出责任或提供隐性担保，属于典型增加隐性债务的违规行为。 |
| **融资平台公司** | Local Government Financing Platforms (LGFPs) | 由地方政府及其部门出资设立、承担政府投资项目融资功能的国有企业，文件明确禁止其作为社会资本参与本级PPP项目，以防债务风险转嫁与政企不分。 |
| **项目资本金** | Project Equity Capital | PPP项目公司中由股东以自有资金认缴并实缴的出资，须符合国家最低比例要求且不得以债务性资金充抵，是风险共担与资本约束的核心载体。 |
| **绩效挂钩付费机制** | Performance-Based Payment Mechanism | 政府付费严格依据项目产出质量、服务标准、公众满意度等可量化绩效指标进行结算，杜绝‘重建设、轻运营’及支出责任固化。 |
| **全国PPP综合信息平台** | National PPP Integrated Information Platform | 财政部主导建设的统一信息披露与监管系统，承担项目库管理、数据归集、风险预警、社会监督等功能，是实现PPP阳光化、标准化运行的技术基础设施。 |
| **隐性债务** | Hidden Local Government Debt | 地方政府在法定债务限额外，通过PPP、政府购买服务、融资平台等渠道形成的、未纳入预算管理但实际承担偿还责任的债务，属中央重点防控的重大财政风险。 |
| **实质性影响** | Substantial Influence | 指政府方通过股权控制、人事任免、重大事项否决权等方式，对融资平台参股国企的经营决策形成决定性干预，使其丧失独立市场主体地位。 |
| **财政支出责任占比** | Fiscal Expenditure Responsibility Ratio | 某地区所有PPP项目年度财政支出责任占该地区当年一般公共预算支出的比重，设定7%预警线与10%红线，构成区域PPP规模总量控制的核心指标。 |
| **社会资本合法权益** | Legitimate Rights and Interests of Social Capital | 包括平等缔约权、合理投资回报权、知情监督权、争议解决请求权等，需通过契约精神、预算刚性约束与司法保障予以落实。 |
| **优质优价采购** | Quality-Oriented Procurement | PPP项目采购中摒弃唯低价导向，综合考量技术方案、运营能力、财务实力与履约信用，以全生命周期成本最优为目标的采购价值理念。 |
| **资产证券化** | Asset Securitization | 将PPP项目未来稳定现金流（如收费权、补贴收益权）打包发行标准化金融产品，拓宽社会资本退出渠道与再融资路径的资本市场工具。 |
| **梯次接续的项目开发格局** | Staggered and Sustained Project Pipeline | 统筹在建、待建、储备三类项目，构建远近结合、滚动推进、风险可控的PPP项目可持续发展生态。 |
| **契约理念** | Contractual Governance | 强调政府与社会资本在PPP关系中恪守合同约定、尊重权利义务对等、坚持法律至上与程序正义的现代治理原则。 |
| **收支两条线管理** | Revenue-and-Expenditure Dual-Track Management | 污水、垃圾处理等特定领域实行收入全额上缴国库、支出由财政统筹安排的财政管理制度，虽形式为政府付费，但因具有准公共服务属性而豁免部分PPP审慎条款。 |
| **民营企业优先支持** | Preferential Support for Private Enterprises | 在同等条件下，对民营企业参与PPP项目在推介、评审、资金支持等方面给予倾斜性政策安排，旨在破除所有制歧视、激发民间投资活力。 |
| **中国PPP基金** | China PPP Fund | 由财政部联合省级财政部门发起设立的国家级政策性引导基金，通过股权投入方式支持规范PPP项目，其绩效考核明确将投资民营项目比例作为核心指标。 |

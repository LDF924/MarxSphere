# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **国家资本主义** (State Capitalism) | State Capitalism | 列宁在新经济政策时期提出的过渡性经济形式，指在无产阶级国家主导下，利用资本主义的生产、经营和管理方式（如租让制、合作社、国家订货等）恢复和发展国民经济，其本质是受国家监督、为社会主义服务的资本主义形态，而非向资本主义制度演变。 |
| **租让制** (Concession System) | Concession System | 苏俄新经济政策下允许外国资本家或本国私人承租国有土地、矿山、森林及部分工业企业，在契约约束和国家监管下进行经营的制度安排，是列宁‘利用资本主义’以获取资金、技术与管理经验的关键实践形式。 |
| **粮食税** (Food Tax) | Food Tax | 取代战时共产主义时期余粮收集制的农业政策，允许农民在缴纳固定实物税后自由处置剩余农产品，从而恢复市场流通与小农经济活力，构成新经济政策在农村的基础性制度安排。 |
| **贸易自由** (Free Trade) | Free Trade | 新经济政策下允许城乡之间、地区之间开展商品交换与私营商业活动的政策，旨在激活地方流转、刺激小工业发展，并作为重建工农联盟、巩固无产阶级专政的经济纽带。 |
| **训练有素的资本主义** (Disciplined Capitalism) | Disciplined Capitalism | 列宁对社会主义国家内资本主义经济成分的理想状态表述，强调其必须严格服从国家法律、接受司法监督、纳入计划轨道，成为受无产阶级政权规训、服务于社会主义建设目标的‘循规蹈矩’经济力量。 |
| **规范引导** (Regulation and Guidance) | Regulation and Guidance | 列宁提出的核心治理理念，指通过立法、司法、行政、工会、意识形态等多维机制，对资本主义经济活动施加系统性约束与方向性引领，确保其消极面被抑制、积极面被转化，实现‘为我所用’的战略目的。 |
| **新经济政策** (New Economic Policy (NEP)) | New Economic Policy (NEP) | 1921年苏俄为应对经济崩溃与政治危机而实施的过渡性战略调整，以粮食税、贸易自由、租让制和国家资本主义为主要特征，本质是在坚持无产阶级专政前提下，利用市场机制与资本主义方法恢复生产力、巩固工农联盟的策略性选择。 |
| **工农联盟** (Worker-Peasant Alliance) | Worker-Peasant Alliance | 列宁视其为苏维埃政权的阶级基础与政治生命线；新经济政策中通过粮食税、市场交换等制度设计，将农民经济利益与无产阶级国家命运相联结，防止小农自发倾向导致的政治离心，是‘规范引导’资本主义的终极政治目标。 |
| **无产阶级专政** (Dictatorship of the Proletariat) | Dictatorship of the Proletariat | 列宁强调其是规范引导资本主义的根本政治前提——所有经济让步与制度安排均以不削弱、不危及无产阶级对国家机器的绝对领导权为底线，资本活动必须始终处于‘谁战胜谁’的政治斗争框架内。 |
| **资本主义习气** (Capitalist Habits) | Capitalist Habits | 列宁对资本主义经济关系复辟可能引发的意识形态腐蚀的警惕性概念，特指投机牟利、官僚主义、小资产阶级无政府倾向等非社会主义思想行为，需通过文化教育、工会监督与纪律惩戒予以抵制。 |
| **路标转换派** (Smenovekhovtsy) | Smenovekhovtsy | 俄国白俄流亡知识分子团体，主张放弃推翻苏维埃政权的幻想，转而承认其现实合法性并期待其自然演变为资产阶级国家；列宁将其视为‘敌人说出的真话’，警示党内须警惕新经济政策被曲解为制度蜕变的危险思潮。 |
| **主权独立前提下的让步** (Concessions under Sovereign Independence) | Concessions under Sovereign Independence | 列宁对外经济交往的基本原则，即在维护国家领土完整、政治自主与经济主权不可侵犯的前提下，以互惠对等为条件与资本主义国家开展贸易、技术合作与外交谈判，拒绝任何侮辱性、附带政治条件的‘让步’。 |
| **人民法院建设** (Judicial System Construction) | Judicial System Construction | 列宁推动的法治化治理举措，要求法院严格依据新颁布的467项法令监督资本主义经营活动，严惩哄抬物价、克扣工资等违法行为，使司法成为规范资本运行、捍卫工农权益的刚性制度屏障。 |
| **工会监督功能** (Trade Union Supervisory Function) | Trade Union Supervisory Function | 列宁赋予工会的核心使命之一，即组织工人同资本作斗争、参与企业管理、推荐干部、普及经济知识，使其成为连接党与群众、规范资本逐利行为、保障劳动者权益的‘社会主义工业学校’与制度性监督主体。 |
| **意识形态工作主动权** (Initiative in Ideological Work) | Initiative in Ideological Work | 列宁强调必须通过党报宣传、马克思主义理论普及、青少年教育、图书馆网络建设等方式，主动阐释新经济政策的策略性本质，破除‘共产主义破产论’‘和平演变论’等错误认知，筑牢社会主义道路自信的思想根基。 |
| **对等原则** (Principle of Equality) | Principle of Equality | 列宁处理国际关系的基本准则，主张社会主义国家与资本主义国家在外交谈判、经贸合作中坚持权利义务对等、相互尊重主权，反对单方面屈从或强加条件，是维护国家尊严与发展空间的底线性规范。 |
| **小资产阶级自发势力** (Spontaneous Petty-Bourgeois Forces) | Spontaneous Petty-Bourgeois Forces | 列宁对自由贸易条件下农村富农、城市私商等阶层政治动向的理论判断，认为其天然具有动摇工农联盟、煽动无政府主义、瓦解无产阶级专政的倾向，必须通过国家干预与思想教育加以遏制。 |
| **经济上的让步** (Economic Concessions) | Economic Concessions | 列宁提出的辩证策略概念，指在特定历史阶段为换取技术、资金与生产力恢复而作出的暂时性制度退让（如租让、市场开放），其价值在于‘以退为进’，最终服务于增强无产阶级国家物质力量的战略目标。 |
| **双重战争论** (Dual-War Thesis) | Dual-War Thesis | 列宁对新经济政策本质的深刻概括：既是一场‘经济战争’（恢复生产、积累实力），更是一场‘政治战争’（防范复辟、捍卫专政），二者统一于‘谁战胜谁’的根本命题，凸显规范引导的极端重要性与斗争尖锐性。 |
| **国家机关改革** (State Apparatus Reform) | State Apparatus Reform | 列宁针对官僚主义、低效腐败等问题提出的治理现代化举措，包括精简编制、整顿作风、强化责任制、培养专业干部，旨在提升国家机器驾驭资本主义经济的能力，使之真正成为‘规范引导’的执行中枢。 |
| **资本主义文明成果** (Civilizational Achievements of Capitalism) | Civilizational Achievements of Capitalism | 列宁所指的资本主义在科学技术、管理方法、组织形式、市场机制等方面的历史性进步，强调社会主义必须批判性吸收这些成果以加速自身发展，而非全盘否定或简单复制其社会制度。 |
| **中国特色社会主义道路** (Socialism with Chinese Characteristics) | Socialism with Chinese Characteristics | 本文将列宁思想当代化的重要落脚点，指中国在改革开放中坚持社会主义基本制度前提下，创造性运用市场机制、多种所有制并存、按要素分配等‘规范引导’实践，形成区别于传统社会主义与西方资本主义的自主发展路径。 |
| **平均主义** (Egalitarianism) | Egalitarianism | 列宁批判的教条主义经济观，指脱离生产力发展阶段、无视劳动差异与贡献差异的僵化分配思想；本文将其作为改革开放前‘封闭僵化老路’的典型表征，反衬‘规范引导’所蕴含的实事求是方法论。 |
| **府际合作** (Intergovernmental Cooperation) | Intergovernmental Cooperation | 虽属文末延伸讨论术语，但在本文语境中被赋予列宁式治理逻辑：指不同层级或区域政府间在职业教育等公共事务中，基于共同目标开展的制度化协作，体现国家统筹下资源再配置与功能协同的现代治理能力。 |
| **历史虚无主义** (Historical Nihilism) | Historical Nihilism | 本文批判的错误思潮之一，指否定中国近现代革命史、抹黑领袖人物、解构主流意识形态的倾向；列宁思想对此的启示在于：必须通过扎实的理论武装与历史教育，捍卫社会主义道路的历史正当性与现实必然性。 |

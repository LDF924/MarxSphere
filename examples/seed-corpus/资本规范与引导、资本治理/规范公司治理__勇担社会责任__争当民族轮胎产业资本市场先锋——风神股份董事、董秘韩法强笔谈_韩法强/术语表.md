# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **公司治理** (Corporate Governance) | Corporate Governance | 指上市公司权力机构（股东大会）、决策机构（董事会）、监督机构（监事会）和经营机构（管理层）之间权责分明、协调运转、有效制衡的制度安排与运行机制，是保障企业合法合规运营、资产安全、信息披露真实准确的基础性制度框架。 |
| **信息披露** (Information Disclosure) | Information Disclosure | 上市公司依据《证券法》《上市公司信息披露管理办法》等法规，及时、真实、准确、完整、公平地向投资者及公众公开财务状况、经营成果、重大事项及风险因素等关键信息的法定义务与实践过程，是投资者关系管理与资本市场信任构建的核心环节。 |
| **关联交易** (Related-Party Transactions) | Related-Party Transactions | 上市公司与其控股股东、实际控制人及其控制的企业之间发生的转移资源或义务的交易行为，在风神股份加入中国化工集团后，该类交易需通过内控制度规范、定价公允性审查及监管沟通实现合规治理，防范利益输送与同业竞争风险。 |
| **内部控制体系** (Internal Control System) | Internal Control System | 依据《企业内部控制基本规范》构建的覆盖公司本部、下属部门及子公司的全流程、全业务、全岗位的风险防控机制，旨在保障经营管理合法合规、资产安全、财务报告真实完整及战略目标有效实现。 |
| **投资者关系管理** (Investor Relations Management (IR)) | Investor Relations Management (IR) | 上市公司通过接待调研、电话会议、推介会、定期报告等多种渠道，主动、专业、合规地与现有及潜在投资者沟通交流，传递公司价值、回应关切、增强市场认同的系统性管理活动。 |
| **同业竞争** (Horizontal Competition with Controlling Shareholder) | Horizontal Competition with Controlling Shareholder | 上市公司与控股股东或其关联方在相同或相似业务领域存在直接或间接竞争关系的情形，构成公司治理重大合规风险，需通过资产整合、业务划分、承诺函及持续披露等方式予以规范与规避。 |
| **实缴资本** (Paid-in Capital) | Paid-in Capital | 股东实际缴纳并经依法验资确认的出资额，区别于认缴资本；虽文中未直接提及，但作为轮胎制造业重资产企业，其资本充实性与实缴到位情况直接影响公司融资能力、偿债信用及监管合规评价。 |
| **绿色轮胎** (Green Tire) | Green Tire | 以低滚动阻力、低湿滑、低噪声为特征，采用环保型加工油、白炭黑替代炭黑等绿色材料与工艺研发的节能低碳轮胎产品，体现企业环境责任履行与技术升级方向，属国家战略性新兴产业重点支持范畴。 |
| **资源节约型、环境友好型企业** (Resource-Efficient and Environment-Friendly Enterprise) | Resource-Efficient and Environment-Friendly Enterprise | 国家推动生态文明建设背景下提出的新型企业范式，强调通过清洁生产、循环经济（如污水‘零排放’‘负排放’）、能耗强度下降等路径实现经济效益与生态效益协同，是企业履行ESG责任的重要政策标识。 |
| **万元产值综合能耗** (Comprehensive Energy Consumption per 10,000 RMB Output Value) | Comprehensive Energy Consumption per 10,000 RMB Output Value | 衡量工业企业能源利用效率的核心指标，指每产出一万元工业增加值所消耗的标准煤总量，文中显示风神股份‘十一五’期间累计下降40%，2010年同比再降4.2%，体现其集约化发展成效。 |
| **世界级制造** (World-Class Manufacturing (WCM)) | World-Class Manufacturing (WCM) | 以精益生产、持续改进、全员参与、数据驱动为特征的先进制造管理模式，文中作为风神股份内部管理升级的战略牵引，旨在提升质量稳定性、成本控制力与运营卓越性。 |
| **品牌价值** (Brand Valuation) | Brand Valuation | 基于市场影响力、消费者认知度、盈利能力与可持续性等维度评估的无形资产量化指标，文中‘风神’品牌价值从36.78亿元升至59.17亿元，反映资本市场对公司软实力与长期竞争力的认可。 |
| **资本运作** (Capital Operations) | Capital Operations | 上市公司依托资本市场平台，通过再融资、并购重组、股权激励、市值管理等手段优化资源配置、支持战略落地、提升产业集中度与核心竞争力的系统性金融活动，文中被明确列为与项目建设并重的‘两个轮子’之一。 |
| **社会责任** (Corporate Social Responsibility (CSR)) | Corporate Social Responsibility (CSR) | 企业在创造经济价值的同时，对股东、员工、客户、社区及生态环境等利益相关方承担的法律责任与道德义务，文中体现为节能减排投入、污水治理、公益行动及‘企业公民’定位。 |
| **持续改进** (Continuous Improvement) | Continuous Improvement | 源于精益管理的核心方法论，指企业通过PDCA循环、六西格玛、QC小组等形式，对工艺、质量、成本、流程等持续识别问题、分析根因、实施优化并标准化的动态管理机制。 |
| **中国化工集团公司** (China National Chemical Corporation (ChemChina)) | China National Chemical Corporation (ChemChina) | 国务院国资委控股的中央企业，2007年成为风神股份控股股东，既是资源整合与技术赋能的战略依托，亦带来治理结构重塑、关联交易规范与央企合规监管适配等制度性挑战。 |
| **上证公司治理指数样本股** (SSE Corporate Governance Index Constituent) | SSE Corporate Governance Index Constituent | 由上海证券交易所编制、反映沪市公司治理水平领先企业的代表性指数成分股，入选标志公司在三会运作、信息披露、内控建设、股东权益保护等方面达到行业标杆水准。 |
| **ESG治理** (Environmental, Social and Governance Governance) | Environmental, Social and Governance Governance | 虽原文未使用该术语，但全文贯穿环境绩效（E）、社会责任（S）与公司治理（G）三维实践，如节能减排、员工关怀、董事会规范运作等，构成中国语境下早期ESG治理的典型实践雏形。 |
| **行业对标** (Industry Benchmarking) | Industry Benchmarking | 企业选取国内外同行业领先者在质量、成本、效率、能耗等关键绩效指标上进行系统性比较分析，识别差距、设定目标、制定改进路径的管理工具，文中被列为提升盈利能力和质量稳定性的核心方法。 |
| **产品结构调整** (Product Portfolio Optimization) | Product Portfolio Optimization | 依据市场需求变化、盈利贡献度分析及技术升级能力，动态调整不同品类轮胎（如全钢载重胎、工程机械胎、高性能乘用胎）的产能配置与市场投放比重，以提升整体毛利率与抗周期能力。 |
| **双轮驱动** (Dual-Drive Strategy) | Dual-Drive Strategy | 文中特指‘项目建设’与‘资本运作’协同发力的发展模式，前者夯实实体根基，后者放大资源效能，共同支撑企业规模化、技术化与国际化战略目标实现。 |
| **企业公民** (Corporate Citizen) | Corporate Citizen | 超越股东利润最大化的现代企业角色定位，强调企业作为社会有机体成员，须在法治框架内对经济、社会与环境系统承担可问责的积极责任，文中体现为‘对股东负责、使员工满意、让社会放心’的三位一体承诺。 |
| **资本市场先锋** (Capital Market Pioneer) | Capital Market Pioneer | 指在规范治理、信息披露、投资者关系、ESG实践等方面率先垂范，并通过良好业绩与品牌价值获得资本市场高度认可的行业龙头企业，体现中国轮胎产业在全球价值链中的话语权跃升诉求。 |
| **高质量发展** (High-Quality Development) | High-Quality Development | 虽为后发政策术语，但全文实践已内嵌其核心要义：以技术创新（绿色轮胎）、效率提升（万元产值能耗下降）、结构优化（产品/市场/发展方式调整）、绿色低碳（资源节约型）与治理现代化（公司治理指数样本股）为支柱的可持续发展模式。 |

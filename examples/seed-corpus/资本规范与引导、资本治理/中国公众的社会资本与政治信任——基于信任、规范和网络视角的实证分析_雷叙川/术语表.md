# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **社会资本** (Social Capital) | Social Capital | 本文沿用帕特南的三维操作化定义，指嵌入于社会关系网络中、以信任（普遍信任）、互惠规范和组织化网络为构成要素的集体性资源，具有促进合作、降低交易成本、提升治理效能的功能性特征。 |
| **政治信任** (Political Trust) | Political Trust | 指公民对政治体系（包括中央政府、人民代表大会、政党、行政机关、法院、警察等）产生符合其期望结果之能力所持有的弥散性信念，是一种基于理性评价与文化积淀的动态性、体系层级的合法性认知。 |
| **社会信任** (Social Trust) | Social Trust | 即普遍信任，指个体对陌生他人或一般性‘大多数人’是否可信所持有的基本态度，区别于基于血缘/熟人的特殊信任，是社会资本的认知维度核心指标。 |
| **互惠规范** (Norm of Reciprocity) | Norm of Reciprocity | 本文界定为社会资本的规范维度，特指公民在人际交往与集体行动中内化并践行的‘关心帮助他人’与‘做有利于社会之事’等义务性价值准则，以双向、非即时性回报为特征，构成政治信任的伦理基础。 |
| **社会网络** (Social Network) | Social Network | 本文将其操作化为结构维度，分为开放型（通过公益/互益组织参与形成的横向联结）与封闭型（基于亲友熟人聚会形成的强关系联结），二者对政治信任具有方向相反的效应。 |
| **开放型社会网络** (Open Social Network) | Open Social Network | 指个体通过自愿加入公益组织（如环保、慈善组织）和互益组织（如专业协会、消费者组织）所构建的异质性、包容性关系网络，能拓展信息渠道、培育公共精神，正向影响政治信任。 |
| **封闭型社会网络** (Closed Social Network) | Closed Social Network | 指个体主要依托血缘、地缘或熟人关系进行日常交往（如家庭朋友聚会）所形成的同质性、排外性关系网络，易强化圈层认同而弱化对体制的普遍信任，对政治信任呈显著负向影响。 |
| **弥散型信任** (Diffuse Trust) | Diffuse Trust | 政治信任的类型学概念，指公民对政治体系整体或抽象组成部分（如‘政府’‘法院’）而非具体政策或官员的泛化信任，反映深层合法性认知，是本文因变量测量的核心指向。 |
| **特定型信任** (Specific Trust) | Specific Trust | 与弥散型信任相对，指公民对政治系统中某一具体对象（如某届政府、某位官员、某项政策）的绩效导向信任，本文未将其纳入测量，强调政治信任应超越短期绩效评价。 |
| **制度范式** (Institutional Paradigm) | Institutional Paradigm | 解释政治信任来源的理论路径，主张信任水平取决于政治系统实际绩效（如公共服务质量、腐败控制效果）带来的理性利益计算，具有短期性与波动性特征。 |
| **文化范式** (Cultural Paradigm) | Cultural Paradigm | 解释政治信任来源的理论路径，强调信任源于长期政治社会化过程中形成的价值观、历史经验与社会资本等文化积淀，具有稳定性与代际传递性。 |
| **溢出效应** (Spillover Effect) | Spillover Effect | 本文用以描述社会信任向政治信任转化的机制：公众在横向人际交往中形成的普遍信任倾向，会无意识地迁移至对纵向政治权威的信任判断中，构成二者关联的心理中介。 |
| **强关系** (Strong Tie) | Strong Tie | 社会网络理论概念，指基于情感亲密、频繁互动与高度义务的紧密联结（如亲属、密友），在本文中对应封闭型网络，具有高信任度但低信息多样性。 |
| **弱关系** (Weak Tie) | Weak Tie | 社会网络理论概念，指互动频率低、情感强度弱但信息桥接功能强的松散联结（如同事、社团成员），在本文中构成开放型网络的重要基础，促进跨圈层信息流动与信任扩展。 |
| **探索性因子分析** (Exploratory Factor Analysis (EFA)) | Exploratory Factor Analysis (EFA) | 本文采用的统计方法，用于检验社会资本（社团参与）与政治信任量表的结构效度，通过KMO值（>0.8）与Bartlett球形检验确认变量间相关性，提取公因子并命名（如‘公益组织’‘政治信任’）。 |
| **二分法赋值** (Dichotomous Coding) | Dichotomous Coding | 本文对多级李克特量表题项（如信任程度、规范认同）实施的数据处理技术，将连续选项按理论阈值转化为0-1虚拟变量（如‘很像/像/有些像’=1，其余=0），以适配回归模型要求。 |
| **控制变量** (Control Variables) | Control Variables | 为排除混杂因素干扰而纳入回归模型的协变量，本文包括人口学变量（性别、年龄、教育、收入）、政治行为变量（传统/非传统参与）、心理变量（政治兴趣、主观阶层）等。 |
| **世界价值观调查** (World Values Survey (WVS)) | World Values Survey (WVS) | 本文数据来源的国际标准化跨国调查项目，2012年中国模块由北京大学中国国情研究中心执行，为本研究提供具有全国代表性的微观实证数据基础。 |
| **帕特南社会资本观** (Putnam's Conception of Social Capital) | Putnam's Conception of Social Capital | 本文理论锚点，强调社会资本是‘社会组织的特征’，由信任、规范与网络三要素共同构成，其功能在于通过促进合作提升集体行动效率与民主治理绩效。 |
| **布尔迪厄社会资本观** (Bourdieu's Conception of Social Capital) | Bourdieu's Conception of Social Capital | 本文引述的奠基性定义，将社会资本视为个体凭借制度化关系网络所获取的实际或潜在资源集合体，强调其工具性与个体策略性运用。 |
| **科尔曼社会资本观** (Coleman's Conception of Social Capital) | Coleman's Conception of Social Capital | 本文引述的结构性定义，认为社会资本是‘社会结构资源’，存在于人际关系之中，其价值体现于促成集体行动与实现个体目标的生产性功能。 |
| **福山规范论** (Fukuyama's Normative View) | Fukuyama's Normative View | 本文引述的规范中心视角，强调社会资本本质上是非正式社会规范（尤其互惠与信任），其塑造人际信任的能力直接决定社会繁荣与制度绩效。 |
| **政治社会化** (Political Socialization) | Political Socialization | 文化范式下政治信任形成的关键过程，指个体在家庭、学校、媒体与社会交往中持续习得政治态度、价值观与行为模式，使社会资本成为稳定信任的深层文化载体。 |
| **公民精神** (Civic Spirit) | Civic Spirit | 本文政策建议指向的核心素养，指公民在互惠规范引导下形成的诚信、友善、公共关怀与协作意愿，是连接社会资本与政治信任的价值中介。 |
| **治理绩效** (Governance Performance) | Governance Performance | 制度范式下影响政治信任的关键中介变量，指政府在公共服务供给、法治建设、廉洁度等方面的实际表现，本文虽未直接测量，但承认其与社会资本存在交互效应。 |

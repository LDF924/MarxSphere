# 术语表

| 术语 | 英文名称 | 学术语境释义 |
| :--- | :--- | :--- |
| **政府和社会资本合作新机制** (New Public-Private Partnership Mechanism) | New Public-Private Partnership Mechanism | 指国务院办公厅转发的《关于规范实施政府和社会资本合作新机制的指导意见》所确立的以使用者付费为核心、优先支持民营企业参与、全面采用特许经营模式的PPP制度安排，旨在防范隐性债务、激发民间投资活力、回归PPP本源。 |
| **使用者付费项目** (User-Pay Project) | User-Pay Project | 指项目经营收入主要来源于终端用户直接支付费用（如水费、电费、通行费、垃圾处理费等），具备稳定现金流预期和自我可持续能力的PPP项目，是新机制下唯一鼓励实施的PPP类型。 |
| **特许经营模式** (Concession Model) | Concession Model | 一种由政府依法授予社会资本在一定期限内投资建设并运营公共基础设施、提供公共服务，并通过使用者付费获取合理回报的契约型公私合作模式，新机制要求所有PPP项目必须采用该模式。 |
| **隐性债务** (Hidden Local Government Debt) | Hidden Local Government Debt | 指地方政府在法定债务限额之外，通过融资平台公司、PPP、政府购买服务、承诺保底收益等方式形成的、未纳入预算管理但实质承担偿债责任的债务，新机制通过聚焦使用者付费从源头予以防范。 |
| **民营企业参与优先原则** (Priority for Private Enterprises) | Priority for Private Enterprises | 新机制明确将民营企业作为PPP新建（含改扩建）项目的首选社会资本方，并按公共属性强弱实行分类股权比例要求（如独资控股、不低于35%、积极创造条件参与），旨在纠正过去国企主导造成的民间投资挤出效应。 |
| **《支持民营企业参与的特许经营新建（含改扩建）项目清单（2023年版）》** (2023 List of Concession Projects Encouraging Private Enterprise Participation) | 2023 List of Concession Projects Encouraging Private Enterprise Participation | 国家发展改革委制定的分类指导性目录，将PPP项目按市场化程度与公共属性分为三类，差异化设定民营企业股权占比下限及参与方式，体现政策精准性与可操作性。 |
| **可行性缺口补助** (Viability Gap Funding (VGF)) | Viability Gap Funding (VGF) | 指政府为弥补使用者付费不足以覆盖成本与合理回报的缺口而提供的财政补贴，新机制明令禁止将其用于PPP项目建设期，仅允许在运营期按规定补贴运营支出。 |
| **可用性付费** (Availability Payment) | Availability Payment | 一种政府基于项目设施是否符合约定标准（而非实际使用量）向社会资本支付的固定费用，新机制严禁以此方式变相固化政府支出责任或补偿建设成本。 |
| **保底收益率承诺** (Minimum Return Guarantee) | Minimum Return Guarantee | 指政府或其平台公司向社会资本承诺项目最低投资回报率的行为，新机制严格禁止此类刚性兑付安排，以厘清政企权责边界、防控财政风险。 |
| **政府资本金注入** (Government Equity Injection) | Government Equity Injection | 指政府以出资人身份向PPP项目公司投入资本金，属于政府投资行为，须纳入《政府投资条例》管理，区别于违规的财政补贴或债务性资金支持。 |
| **社会资本** (Social Capital) | Social Capital | 在PPP语境中特指依法设立、具备相应投融资与运营管理能力的境内企业（含民营企业、国有企业、外商投资企业），不包括政府融资平台公司，新机制强调其独立市场主体地位。 |
| **民间投资** (Private Investment) | Private Investment | 由境内非国有控股企业（含民营企业、个体工商户、合伙企业等）以自有资金或市场化融资开展的固定资产投资活动，是稳增长、促转型的关键动能，新机制旨在系统性激活其参与基础设施领域的积极性。 |
| **资本要素配置** (Capital Factor Allocation) | Capital Factor Allocation | 指通过制度设计引导资本流向符合国家战略导向、具有真实需求和可持续回报的领域，新机制通过项目筛选标准、参与主体导向和回报机制重构，优化基础设施领域资本要素的结构性配置。 |
| **高质量发展** (High-Quality Development) | High-Quality Development | 以创新、协调、绿色、开放、共享为理念，强调全要素生产率提升、供给体系韧性增强与共同富裕协同推进的发展范式，民营企业科技创新与PPP新机制均服务于这一核心目标。 |
| **中国式现代化** (Chinese Path to Modernization) | Chinese Path to Modernization | 以人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路为特征的现代化道路，民营经济壮大与规范PPP治理是其在经济制度层面的重要支撑。 |

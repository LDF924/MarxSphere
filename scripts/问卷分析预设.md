# 农村经营形态问卷 — 实证分析预设(用于 MarxSphere 实证工作台)

> 配套文件:`问卷变量模板.csv`(167 个题项)、`问卷选项编码表.md`(选项值对应关系)。
> 数据要求: 一行一受访者; 列名 = 模板中的变量名; 跳转未答题编码 -99(未适用), 拒答/漏答 -88。
> 运行方式: 在"实证研究"页(#empirical-research)粘贴 CSV / 选 PG 表 → 选方法 → 按本文参数填表单 → 运行。

---

## 流程 1 描述统计(Table 1)— 方法 `descriptive`

**目的**: 全样本描述, 论文 Table 1。

**数据**: 全量问卷(167 列)。

**参数**:

| 参数 | 值 |
|---|---|
| cols | `identity, hh_size, gender, age, edu_years, politics, village_duty, hukou, employment, cult_area, own_area, transfer_in_area, transfer_out_area, n_parcels, adj_willing, continue_will, abandon_right_will, nonfarm_income, avg_yield, ins_buy` |

> 说明: 数值列输出 均值/SD/N/Min/Max; 分类列输出 N。cols 留空则全变量统计(建议先全跑一次摸底, 再用上表精选做论文 Table 1)。

**后续扩展**(每个主题一张表):
- 表 1a 土地特征: `cult_area, own_area, transfer_in_area, transfer_out_area, reclaim_area, basic_farm_area, paddy_area, irrigable_area, n_parcels`
- 表 1b 经营: `sown_area, avg_yield, total_yield, mech_service_cost, hire_cost, input_cost, input_cost_share, subsidy_total`
- 表 1c 意愿: `adj_willing, continue_will, prospect_view, abandon_right_will, village_motive_change`

## 流程 2 交叉表: 身份 × 调地意愿 — 方法 `crosstab`

**目的**: 不同经营主体类型对二轮承包到期后调地意愿的分布差异(卡方 + Cramér's V)。

**数据**: 全量问卷(需要 1-1 identity、2-15 adj_willing 两列即可)。

**参数**:

| 参数 | 值 |
|---|---|
| row | `identity` |
| col | `adj_willing` |

**输出**: 频数表 + 行百分比表 + 卡方检验(χ², p) + Cramér's V。

**衍生分析**(同法换参):
- `identity × continue_will` — 身份 × 继续种地意愿
- `hukou × adj_willing` — 户籍 × 调地意愿(本村 vs 外地)
- `employment × transfer_out_area>0`(先 filter 生成哑变量, 再交叉) — 就业状态 × 是否转出
- `gender × abandon_right_will` — 性别 × 有偿退出承包权意愿

## 流程 3 Logit: 是否转出土地 ~ 家庭特征 — 方法 `genvars` → `filter` → `logit`

**目的**: 识别土地转出决策的家庭/个人驱动因素。

**步骤 1 — 变量构造(`genvars`)**: 由 2-4 生成是否转出哑变量(先做这一步, 后续流程共用)。

| 参数 | 值 |
|---|---|
| formulas | `[{"name": "has_out", "expr": "transfer_out_area > 0"}]` |

> 验证: 结果表出现 `has_out = transfer_out_area > 0`, 无"构造失败"警告。

**步骤 2 — 子样本(`filter`)**: 限定有承包地的农户(2-2 有承包地才算有转出资格)。

| 参数 | 值 |
|---|---|
| conditions | `[{"col": "own_area", "op": ">", "value": 0}]` |

**步骤 3 — 回归(`logit`)**:

| 参数 | 值 |
|---|---|
| y | `has_out` |
| xs | `age, edu_years, hh_size, gender, own_area, n_parcels, off_farm, nonfarm_income, identity, cadre` |
| link | `logit`(或 `probit` 做稳健性) |

**解读要点**: 系数 >0 → 该因素提高转出概率; 关注 `own_area`(承包地越多越可能转出)、`off_farm`(非农就业促进转出)、`nonfarm_income`。`identity` 为多分类, 建议后续转哑变量分组回归。

**稳健性**: link 换 `probit`; 或 y 换 `has_in`(是否转入)做对照。

## 流程 4 有序 Logit: 调地意愿 ~ 教育/面积/身份 — 方法 `ologit`

**目的**: 二轮承包到期后调地意愿(1-5 有序)的影响因素。

**数据**: 全量问卷。

**参数**:

| 参数 | 值 |
|---|---|
| y | `adj_willing` |
| xs | `edu_years, cult_area, identity, hh_size, gender, age, n_parcels, hukou, village_duty` |

**输出**: 系数/SE/p/95%CI + 系数图; 阈值参数已省略。**注意**: 本问卷意愿编码为 1=非常愿意→5=非常不愿意,**系数 >0 表示更不愿意调地**, 解读时需反向。

**同族分析**(同法换参):
- `continue_will ~ xs` — 继续种地意愿
- `abandon_right_will ~ xs` — 有偿放弃承包权意愿(政策含义强)
- `input_burden ~ xs` — 农资负担感知
- `water_sat ~ xs` — 水利满意度

## 流程 5 变量构造建议(衍生变量库)— 方法 `genvars`

**目的**: 一次性构造核心论文变量。按下列分组复制 formulas 即可。

### 5.1 流转类(核心)

```json
{"name": "has_out", "expr": "transfer_out_area > 0"}
{"name": "has_in", "expr": "transfer_in_area > 0"}
{"name": "transfer_rate", "expr": "transfer_out_area / own_area"}
{"name": "transfer_in_rate", "expr": "transfer_in_area / own_area"}
{"name": "net_in_area", "expr": "transfer_in_area - transfer_out_area"}
{"name": "out_strength", "expr": "out_area / own_area"}
{"name": "out_rent_ln", "expr": "log(out_cash_rent)"}
```

> 流转率=转出面积/承包面积(2-4 ÷ 2-2); 净转入=转入-转出; 注意分母为 0 时结果 NaN, 工作台会保留为缺失。

### 5.2 收入/结构类

```json
{"name": "mu_income", "expr": "nonfarm_income / cult_area"}
{"name": "ln_nonfarm", "expr": "log(nonfarm_income + 1)"}
{"name": "paddy_share", "expr": "paddy_area / cult_area"}
{"name": "irrig_share", "expr": "irrigable_area / cult_area"}
{"name": "basic_share", "expr": "basic_farm_area / cult_area"}
{"name": "fragment", "expr": "n_parcels / cult_area"}
{"name": "cropping_index", "expr": "sown_area / cult_area"}
{"name": "yield_per_mu", "expr": "total_yield / cult_area"}
{"name": "subsidy_share", "expr": "subsidy_total / (subsidy_total + nonfarm_income)"}
{"name": "agri_income", "expr": "total_yield * avg_yield / 10000"}
```

### 5.3 虚拟变量/重编码类

```json
{"name": "age", "expr": "2023 - (birth_ym // 100)"}
{"name": "is_farm", "expr": "((identity == 2) | (identity == 3) | (identity == 6)) * 1"}
{"name": "female", "expr": "(gender == 2) * 1"}
{"name": "party", "expr": "(politics == 2) * 1"}
{"name": "cadre", "expr": "((village_duty == 2) | (village_duty == 3)) * 1"}
{"name": "off_farm", "expr": "((employment == 2) | (employment == 3)) * 1"}
{"name": "adj_will_bin", "expr": "(adj_willing <= 2) * 1"}
{"name": "ins", "expr": "(ins_buy == 1) * 1"}
{"name": "mech_use", "expr": "((mech_service == 2) | (mech_service == 3) | (mech_service == 4) | (mech_service == 5) | (mech_service == 6)) * 1"}
{"name": "edu_years", "expr": "((edu == 1) * 0 + (edu == 2) * 6 + (edu == 3) * 9 + (edu == 4) * 12 + (edu == 5) * 12 + (edu == 6) * 12 + (edu == 7) * 15 + (edu == 8) * 16 + (edu == 9) * 19)"}
{"name": "has_nonfarm", "expr": "(nonfarm_income > 0) * 1"}
```

> 注: 布尔比较会生成 True/False 列, 用 `* 1` 转 0/1; 多选"可多选"题目建议拆成每选项一列哑变量(如 `r1..rk`), 由录入阶段处理。

### 5.4 构造后建议流程

```
genvars(5.1+5.3) → descriptive(Table 1) → logit(has_out) → ologit(adj_willing) → 按 identity/区域分组 filter 后再回归
```

## 附录 B: 数据录入/编码约定

1. 列名 = 模板 `变量名` 列(全小写下划线), 不要用题号做列名。
2. 单选: 填选项编码(1/2/3…); 有序类直接填 1-5/1-6。
3. 多选(可多选): 每选项一列 `变量名_rN` 填 0/1(如 `out_reason_r3` 表示选了"流转价格比较满意")。
4. 连续题: 填实际数值(亩/元/斤/%)。
5. 跳转未答: `-99`; 拒答/漏答: `-88`(回归前用 filter 或预处理剔除)。
6. 出生年月 YYYYMM 数字型, 年龄用 `age = 2023 - (birth_ym // 100)` 生成。
7. 1-10 就业状况原文选项有跳号(1-6, 8), 编码表按原文保留; 录入时若无"7 其他"则选项 8 即"其他"。

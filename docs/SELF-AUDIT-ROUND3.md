### 补充(198b676): 编辑器自动保存闭包 Bug(T1 真浏览器实测唯一硬伤)

**现象**: 浏览器输入正文后列表字数 0、版本链只有 v1——"保存没用"。
**根因**: `saveNow` 防抖回调读渲染期闭包 content/title; 1.5s 后触发时 content 仍是旧快照 → PUT 永远发旧内容(新建后首版为空)。
**修复**: `onContentChange` 捕获最新值快照传参 `saveNow(snap)`, 回调不读过期闭包。
**实证**: DB 两次输入 → word_count=35 + ver_n=3(v2/v3 落库); 修复前 net诊断文档 ver_n=1。
**教训**: React 防抖闭包是"看着有、实际不落"的典型; 浏览器驱动是唯一能抓到的途径。

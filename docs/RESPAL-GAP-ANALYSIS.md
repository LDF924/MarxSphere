# Respal(研伴)→ MarxSphere 能力差距对照

> 2026-09-04 · 分析对象: 研伴 Respal(闭源商业产品, respal.cn; Tauri2+SolidJS, ¥39-199/月)
> 信息来源: 官网 + CSDN/快科技/头条公开报道(2026-04 上线)
> 注: Respal 闭源无仓库, 本文为**功能体验层对照**(哪些值得 MarxSphere 参考思路), 非源码移植。

## 一、Respal 能力 vs MarxSphere 现状

标注: ●=已有等价或更强 / ◐=部分有 / ○=缺或弱

### A. 核心工作流

| Respal 能力 | MarxSphere 现状 | 评价 |
|---|---|---|
| 项目级智能体(进项目文件夹干活) | agent_workspace + file_read/write/apply_patch + 项目制 | ● 等价 |
| 90 学术技能 + Skills 广场(社区共享) | 190+ 技能(超 Respal)+ 技能导入导出 | ● 更强(数量与社区生态不同) |
| 2.2 亿文献库元数据 | 自建文献库(本地论文)+ PG/Graphiti/Cognee | ◐ 各有所长: Respal 广(海量元数据), MarxSphere 深(本地全文+图谱) |
| 跨会话记忆 | OpenViking 长期记忆 + 5 层记忆 | ● 等价 |
| 内置 Python 数据清洗/统计/出图 | 实证工作台 17 方法 + 代码沙箱 | ● 更强(方法体系化) |

### B. 写作链路(Respal 最强卖点区)

| Respal 能力 | MarxSphere 现状 | 评价 |
|---|---|---|
| **大纲编辑器: 标题层级树 + 拖拽改结构 + 分章节生成(前后文连贯)** | 无专门大纲拖拽 UI(写作是场景 API 输出) | ○ **真差距(体验层)** |
| **人机双写**(AI 起草框架/数据, 人判断表达) | 写作场景有 LLM 草稿+人工确认(实证闸门类似) | ◐ 部分有, 无编辑器式双写 |
| 一键导出 Word/Markdown/PDF | 格式评测 docx 上传/处理有, 写作导出链弱 | ○ **差距(写作→docx 导出)** |
| 图表节点插入正文 | 写作场景可插图表? | ◐ 需核 |
| 参考文献格式自动转换 | 引文格式化场景(S52) | ● 有 |

### C. 周边场景

| Respal 能力 | MarxSphere 现状 | 评价 |
|---|---|---|
| PPT 生成(Slidify 关联产品) | 无专门 PPT 生成 | ○ **差距**(但 Slidify 是独立产品非 Respal 本体) |
| 论文质检(格式/逻辑/查重预检) | 格式智能评测 23 项 + 论文质量场景 | ● 等价(格式层面更强) |
| 审稿回复信 | 有 rebuttal/审稿回复能力? | ◐ 部分 |
| IM 机器人(钉钉/飞书) | 已有 IM 接入(飞书/钉钉/Telegram) | ● 等价 |
| 定时任务(周期文献检索/分析) | 任务队列 + 定时任务(有) | ● 等价 |
| 网页采集/表格提取/批量下载 | web_fetch/抓取工具 | ◐ 部分 |
| 数据与资料抓取 | web_search/web_fetch/browser_control | ● 更强(新加浏览器控制) |

## 二、结论: 真差距 Top 3

1. **大纲式写作编辑器 UI**(标题树+拖拽+分章生成+图表插入) — Respal 最大差异化卖点, MarxSphere 缺编辑器形态
2. **写作→docx 一键导出**(分章产物直接成稿) — 与格式评测闭环可打通
3. **PPT 生成** — 若需学术 PPT 可借 Slidify 思路或自研

## 三、建议

- MarxSphere 能力底座(技能/记忆/实证/文献图谱)全面强于或等价于 Respal, **差距集中在"写作交付形态"(编辑器+导出)**
- 参考优先级: ①大纲编辑器(做成写作场景的可视化工作台) ②写作导出 docx(与格式评测/指纹保护打通: 草稿→成稿→格式自检闭环)
- Respal 的"2.2 亿文献元数据"提醒: MarxSphere 若接 OpenAlex/Crossref 元数据可补"检索广度"(已有 OA 回退能力, 可扩)

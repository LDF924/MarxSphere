# MarxSphere 项目说明

**项目名称**：MarxSphere 马研星环

**行业赛题**：AI + 教育（马克思主义理论科研教育智能化）

**目标用户**：马理论研究者（研究生/学者）、高校思政教师、政经科研人员

**核心问题**：马理论科研教育存在"三难"：文献检索难——500+ 篇论文跨文献的概念演变难以发现；研究链路难——选题、调研、论证、写作缺乏方法论工具；实证落地难——研究者不具备统计建模能力。

**解决方案**：①事件中心知识图谱，检索从关键词升级为多跳推理；②52 步可解释推理链路，每步带检索来源；③66 科研场景工作台覆盖研究全生命周期；④AI Agent 与实证工作台，检索写作、问卷到回归全流程自动化。

**创新点**：①事件中心检索结构，多跳召回优于纯向量；②三库异构图谱融合；③评测驱动自愈闭环；④马理论方法论沉淀。

**开放/复用价值**：AGPL v3 + 商业授权双许可（保留 Logo、衍生开源，闭源商用需授权）、OpenAI 兼容接口无锁定；数据本地存储导出即迁移；对外 MCP + REST API 可被任意 Agent 调用；检索内核、Agent 编排、实证管道、评测框架可独立复用。

**当前进展**：三库图谱 501 篇入库、21,337 实体；53 题 32 指标评测综合分 0.884；AI Agent 50+ 能力、154 测试全绿；桌面端与实证工作台已完成。

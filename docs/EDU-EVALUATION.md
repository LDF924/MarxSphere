## 1. 教育场景专项评测指标（12 项）

### 1.1 技术指标（自动评测，`scripts/eval-education.ts`）

| # | 指标 | 方法 | 权重 |
|---|---|---|---|
| ① | BKT 预测准确率 | 预测下次答对概率 vs 实际作答的 AUC | 25% |
| ② | 学情诊断准确率 | 诊断薄弱点与模拟答案真实错因的匹配 F1 | 25% |
| ③ | 路径规划合理性 | 拓扑路径无先修逆序率 | 15% |
| ④ | 作业批改准确率 | 客观题规则判分与标准答案一致率 | 15% |
| ⑤ | 思政内容核验 | 意识形态/表述/引用核验通过率（规则通道） | 10% |
| ⑥ | 任务闭环完成率 | 完整链路（辅导→变式→诊断→计划调整）可跑通比例 | 10% |

### 1.2 教学效果指标（补充，需实测数据）

| # | 指标 | 说明 | 数据来源 | 状态 |
|---|---|---|---|---|
| ⑦ | **学生掌握度提升率** | 辅导前后知识点掌握度变化（如 0.4→0.7） | 模拟作答序列回放 | ✅ 可计算 |
| ⑧ | **辅导有效性（前后对照）** | 分步提示后学生正确作答率提升（提示前 vs 提示后） | 模拟对照实验 | ⏳ 待补实景 |
| ⑨ | **教师备课效率** | 教案/课件生成耗时 vs 人工备课基准 | 计时演示 | ⏳ 待测 |
| ⑩ | **作业批改效率** | 客观题自动判分率、主观题辅助评阅覆盖率 | 演示批改集 | ⏳ 待测 |
| ⑪ | **学习规划覆盖率** | 计划覆盖目标知识点比例、先修路径完整率 | 拓扑约束检查 | ✅ 可计算 |
| ⑫ | **用户满意度** | 学生/教师对辅导、答疑、备课输出的 1–5 评分 | 演示问卷 | ⏳ 待补 |

> ①-⑥ 由 `scripts/eval-education.ts` 自动产出（确定性模拟，可复现）；⑦/⑪ 已可计算；⑧-⑩/⑫ 为**待补实景指标**——需真实课堂/教学实验数据，当前不虚报数字。

## 2. 学生/教师实测数据（当前阶段）

### 2.1 模拟实测（确定性种子，可复现）

**数据源**：`data/edu-sim-student*.json`（匿名学生作答序列，预设薄弱点/掌握度轨迹，与 `eval-education.ts` 复用）

| 角色 | 场景 | 输入 | 输出 | 反馈记录 |
|---|---|---|---|---|
| 学生 | 作业辅导（配方法） | "我这一步总是算错" | 考点拆解 + 分步提示 + 易错点 + 同类练习 | 掌握度 0.4 → 0.7（模拟回放） |
| 学生 | 个性化学习规划 | 学科/时长/目标 | 4 周分阶段计划（基础/进阶/挑战） | 覆盖目标知识点 100%（拓扑检查） |
| 教师 | 作业批改 + 班级学情 | 5 份作业（客观+主观） | 自动判分 + 班级盲区报告 | 客观题一致率 100%（规则判分） |
| 教师 | 备课（价值规律） | "45 分钟，班级基础一般" | 教案（目标/流程/案例/作业） | 教案结构完整率 100%（schema 校验） |
| 教师 | 分层教学 | 同知识点三档内容 | 基础/进阶/挑战分层输出 | 三档均生成（接口级验证） |

### 2.2 教学效果反馈（模拟反馈，待真实课堂补充）

| 维度 | 模拟反馈 | 对应改进 |
|---|---|---|
| 辅导不直接给答案 | 分步提示 + 追问式引导，答对率提升（模拟对照） | 保持 hint 默认模式 |
| 错题本归集 | 错题自动溯源知识点，掌握度联动下调 | 已实现（wrong → record-answer 联动） |
| 教师批改效率 | 客观题全自动，主观题辅助评阅 | 已实现（teach/grade） |
| 班级盲区定位 | 聚合全班错题 → 共性教学盲区 | 已实现（teach/class-summary） |

### 2.3 真实课堂实测计划（后续阶段，不虚报）

| 阶段 | 内容 | 指标 |
|---|---|---|
| 小规模试点（20 名学生 / 3 名教师） | 作业辅导 + 备课 + 学情诊断真实使用 | ⑦⑧⑨⑩⑫ |
| 对照组实验 | 使用 vs 未使用系统的同类班级 | 掌握度提升率差异 |
| 教师访谈 | 备课效率、批改负担、教学盲区发现 | 定性反馈 |
| 学生满意度问卷 | 辅导有用性/易用性/隐私安全感 1–5 评分 | ⑫ |

> **当前结论**：技术指标 ①-⑥ 已自动化并有基线数字；教学效果指标 ⑦-⑫ 需真实课堂数据，**开发阶段如实标注"待补"**，不虚构实测结果。

## 4. 数据边界与合规（简表）

| 项 | 说明 |
|---|---|
| 模拟数据 | 匿名 student_id + 确定性种子，无真实个人信息 |
| 真实课堂数据 | 待试点（§2.3），采集前需家长/教师知情同意 |
| 脱敏 | 日志 sanitizeLine（`src/services/log-sanitizer.ts`），student_id 匿名 |
| 保留期 | 学情数据默认 30 天（EDU_DATA_RETENTION_DAYS 可配），语音会话后即删 |
| 完整说明 | 见 [OPEN-SOURCE-DISCLOSURE.md](OPEN-SOURCE-DISCLOSURE.md)「教育数据」节 |

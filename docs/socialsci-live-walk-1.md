## 已走查页: /workflow/input → sections → materials(全链打通)

### 1. /workflow/input 录入门(有积分, 空主题态)
- 主题/字数(默认 10000+说明)/研究框架(+一级章节/插入模板/清除目录)/额外要求/研究方法三卡(定性/定量/混合)/参考文件拖拽/agent引导提问(推荐)/开始思考科研架构/返回
- **插入模板**: 真实点击后目录 3章6节→**5章12节**(五段式社科骨架: 引言/文献综述与分析框架/现状描述或案例呈现/问题分析与对策建议/结语)
- **清除目录**: 真实点击触发确认层, 目录回 3章6节(=恢复页面默认骨架, 非清空)
- **agent引导提问**: 
  - 主题或目录为空 → 错误卡"请先填写研究主题和目录后再生成引导问题"+"请修正输入内容或稍后重试,不会自动生成替代问题。"+重新生成引导问题按钮
  - 填写主题+3章标题+子节后点重新生成 → 建 workflow job(轮询 /api/workflow/jobs/active)+"AI 正在分析你的研究...调用大模型理解内容并生成针对性问题,最长约 3 分钟"
  - **实测后端分析挂起超 5 分钟**(>自称最长 3 分钟)不返回, 轮询停 → 记: 闭源 clarify 无超时兜底
- **开始思考科研架构**: 点击后常驻"正在打开科研工作流"transition overlay(z-index 48) — 首次点击动画卡住(overlay opacity 0 但拦截所有点击), 移除 overlay 后再次点击正常进入 sections
- **静默门禁**: 章节标题(一级+子节)必须真实填值(仅展开模板结构不填标题 → 点击无任何请求无提示, 即静默失效)

### 2. /workflow/sections 架构确认页(AI 分析完成态)
- Toast: "章节清单已生成"
- 流程条: 3 步=变量识别/框架分析/Skill 生成(分析中: Step x/3 + "后台生成中,可安全切换页面或刷新"; 完成: 章节分析完成)
- 分析中: 每章节卡标"AI 正在分析该章节…"; 取消按钮; 底部"AI 分析中,请稍候…"+返回修改
- **完成态内容(关键)**: 
  - 科研框架概览=①变量识别 ②研究假设(H1-H4 带理论依据) ③研究逻辑(三段式递进"起承转"叙述) 
  - 变量识别: 共 6 个(自/因/双中介/调节/控制), 每个变量=名称+类型+语义描述(含操作化线索)
  - 研究假设: 共 4 条, H1主效应/H2H3中介/H4调节, 每条=假设文本+(基于 XX 理论与 XX 假说+机制解释)
  - 研究方法: "定量研究 / 已由你选择"
  - 每章 Skill 卡: 章节名+AI 写作指导+skill key(intro/literature/theory)+**字数(Phase 1 分配)**+写作要点列表+"避免"清单+衔接说明
  - 分析完成 ≈ **2-3 分钟**(3章小项目)
- 按钮: 确认科研架构,进入素材准备 / 返回修改
